### R3-1 · bug · 低 —— 从 3D（或室内）切回 2D 后，色带图例不会回来
- 复现：
  1. 装修 → 选卧室 2 → 墙面换墨绿：2D 里出现色带（6 条），图例显示；
  2. 切到 3D 俯瞰：图例隐藏 ✓；
  3. 切回 2D 平面，等 3 秒：色带还在（6 条），**图例仍然隐藏**。
- 室内视角按「1」回 2D，结果一样。要再点一下别的房间，或者退出装修再进来，图例才重新出现。
- 证据：`s26c/r4.mjs` 的输出（`back 2D (3s) {"legend":"none","bands":6,"view":"2d"}` → 点另一个房间后 `flex`）、`shots26c/r4-back2d.png`。
- 怀疑位置：`app.html:21969` 在切到 3D 时调了 `bandLegendUI(false)`，但切回 2D 的路径上没有重新调 `bandLegendUI`（它在下一次画色带时才更新）。
