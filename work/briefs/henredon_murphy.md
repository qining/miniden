## 结构组成（从参考图反推，建模前必须写死）
1. **木质旋转底座**：实心圆盘，直径 ≈ 19.8" = **50.3 cm**（从 g6 正交背视图 769px/38.8px·in⁻¹ 量出），
   高 ≈ 9 cm，边缘有倒角。官方未写，属图像反推。
2. **桶形外壳（tub / barrel shell）**：一条**连续**的弧形软包带，从前端左 → 后 → 前端右，
   厚度 ≈ 12.7 cm。顶边是 waterfall：后中最高 76.46 cm，到扶手前端降到 64.0 cm。
   背视图（g6）顶边是一条浅弧（中间最高，两端略低），没有"耳朵"。
3. **座垫**：宽 53.85 cm（正好等于外壳内开口宽度），前缘与最大深度平面齐平，
   顶面 48.0 cm，从底座顶面（≈9 cm）一直向上——正交前视图里座垫前立面高约 43 cm，
   不是薄坐垫，而是厚软块。
4. **靠背内面板**：外壳内侧，俯视（v6）U 形开口内可见的那块圆角矩形。

## 轴向（写死，防止 90° 写反）
- 宽 = **x**（79.25 cm），深 = **z**（74.93 cm），**+z = 前**
- 外壳中心线椭圆半轴：Ax = 33.275，Az = 31.115；外半轴 39.625 / 37.465；内半轴 26.925 / 24.765
- 外壳覆盖角 θ ∈ [-110°, +110°]（θ 从正后方向 -z 起算）；前端开口 ±70°

## 曲线拟合（g6 正交背视图逐行/逐列量出，15.19 px/cm）
- **外壳向下收窄**： silhouette 宽度 vs 高度 → 最小二乘 `taper(y) = 1 − 0.22·(1 − y/H)^1.48`
  （实测 79.0cm@72.7 → 76.7@56.7 → 70.4@26.7 → 66.3@16.7；底座 Ø50.2）
- **顶边 waterfall**：背段水平到 |x|≈38cm（θ≈73°），之后线性降到扶手端
  `hgt(θ) = H − (H − 64.0)·clamp((|θ| − 73°)/39°, 0, 1)`；θ=90° 实测降 5.5cm，式给 5.4cm
- 座垫每一层的边界 = 该高度外壳内腔弧 + 前口圆弧（圆弧过内弧两端与 (0, Bout)），
  所以前立面直达整椅最前点，俯视轮廓连续
