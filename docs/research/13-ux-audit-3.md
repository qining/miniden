# 13 · UX 第三轮审计：摆家具的主路径还缺什么（2026-10-25）

> 触发：用户 2026-10-25 ——「是不是已经 UX 方面没有需要提高的地方了？如果有的话，继续吧。」
> 范围：research/11 的 G1–G16 与 research/12 的 W1–W12 / K1–K10 都已落地。这一轮按 homeowner 的主路径**逐个任务走一遍**
> （加一件 → 放得下吗 → 摆整齐 → 比较几种摆法 → 买），每条都带证据（截图读数或代码位置），判据仍是 research/11 那条：
> 回答「东西放哪 / 放不放得下 / 看起来怎样」的做，回答「怎么施工」的不做。

## 1. 走查记录（事实）

| 任务 | 现状 | 证据 |
|---|---|---|
| 加一件 | 点目录卡片 = 放到**当前视图正中**（取 0.25ft 格），不看那儿有什么：个人户型一开就落在中岛上 | `addItem`：`cx=(vb.x+vb.w/2)/S` 原样落下；黄金截图 `2d-sel` 里 Lunix 压在中岛上 |
| 加一件（拖进来） | 目录卡片**不能拖**到平面图上——只能点一下落到中间、再拖过去 | 全文无 `dragstart` / `draggable` |
| 放得下吗 | 红框判据：家具 ↔ 家具、墙 / 窗 / 柱、楼梯、门扇、顶到天花。**不判洁具（马桶 / 浴缸 / 台柜 / 洗手盆 / 淋浴）、画的台面、中岛、内置厨房** | `drawFurniture` 冲突循环只吃 `placementObstacles()`（墙多边形 + 结构柱）；截图里沙发压着中岛不红 |
| 摆整齐 | 拖动中只标**到墙皮**的距离；离旁边那件家具多远（床头柜到床、茶几到沙发、餐椅到餐桌）要自己量 | S18 `distGuides` 只算墙皮 |
| 摆整齐（斜墙） | 贴墙吸附只在「已经差不多平行（±3°）」时才吸；个人户型的斜墙（客厅西北、阳台）要靠旋转手柄 1° 一格去凑角度 | `snapBox` ±3° |
| 检视面板 | 「旋转」一行（框 64px + ° + 滑块 104px + 「+90°」）比面板宽：**「+90°」被切掉一半、面板底部出横向滚动条**（1700 / 1440 / 1280 宽都是） | 截图：右边缘只剩「+9」 |
| 笔记本屏幕 | 1280×800：两侧面板 400 + 300px，平面图只剩 ~570px；底部提示行折成 **5 行**盖住画布下沿。1440×900 也有 4 行 | 截图 `ui_1280x800` / `ui_1440x900` |
| 比较几种摆法 | 一份户型只有一套家具摆法。想试「沙发靠窗 / 沙发靠墙」两种：只能导出布局文件再导回来，或者新建户型从头摆 | 户型注册表只有户型，没有「方案」 |
| 挑家具 | 目录只能搜名字 / 分类；**不能按尺寸筛**（「这面墙 2m，哪些沙发放得下」） | `#catSearch` 只按名字 |

## 2. Gap 清单

P0 = 给出错误的「放得下」答案，或看得见的界面缺陷；P1 = 主路径上每天都要做、现在很费劲；P2 = 有价值、可以晚一步。

| # | Gap | 优先级 | 方案要点 | 路线图 |
|---|---|---|---|---|
| U1 | 家具压在洁具 / 台面 / 中岛 / 内置厨房上不提示 | P0 | 这些固定构件进冲突判据：占地多边形 + 高度区间（马桶 0–78cm、浴缸 0–49cm、台柜 / 洗手盆 0–80cm、淋浴 0–195cm、镜子 93–194cm；台面按台面高、冰箱模块按 ~180cm；中岛 0–91cm；内置厨房按各块的盒子）；椅子 / 凳子塞进台面 / 中岛下面不算（与「椅子塞进桌下」同一条规则）；红框 + 悬停说「压在固定构件上」 | S24a |
| U2 | 新加的家具落在视图正中，不管那儿有什么 | P0 | 从视图中心往外螺旋找第一个**放得下**的位置（在地板里、不插墙、不压家具 / 固定构件 / 楼梯）；找不到才落正中（照旧标红） | S24a |
| U3 | 检视面板旋转那一行溢出 | P0 | 滑块按剩余宽度伸缩（`flex:1`），「+90°」不再被切、面板不出横向滚动条 | S24a |
| U4 | 笔记本屏幕上提示行太高、两侧面板太宽 | P0 | 面板缺省宽度随窗口缩放（目录 `clamp(260px, 24vw, 400px)`、检视 `clamp(240px, 21vw, 300px)`；1700 宽与今天一样）；提示行窄屏只留第一行 + 「? 全部快捷键」，并能一键收起（记住） | S24a |
| U5 | 目录卡片不能拖进平面图 | P1 | 卡片可拖：拖到平面图上松手 = 放在松手处（贴墙吸附照旧；拖动中就画出占地虚框）；3D 俯瞰同样能拖进去 | S24b |
| U6 | 拖动时看不到离旁边家具多远 | P1 | 距离标注加「最近的家具」：四个方向各找迎面最近的一件（家具或固定构件），标出间距（与到墙皮的标注同一套样式）；吸附：两件对齐边差 < 6 屏幕像素就对齐（「对齐线」） | S24b |
| U7 | 斜墙要手动凑角度 | P1 | 拖到墙边、朝向与墙差 ≤ 12°：自动转到与墙平行再贴上（Alt 不吸）；R 键在 15° 一格之外多停一下「最近那面墙的角度」 | S24b |
| U8 | 一份户型只有一套摆法 | P1 | 「方案」：同一份户型存几套家具摆法（缺省「方案 1」），可新建 / 复制当前 / 改名 / 删除 / 切换；每套各自撤销、各自的采购清单；户型几何只有一份（改墙所有方案都跟着） | S24c |
| U9 | 目录不能按尺寸筛 | P2 | 搜索框旁「宽 ≤ __ cm」「深 ≤ __ cm」两个可选筛选；有选中家具时多一个「和它一样大以内」 | S24d |
| U10 | Ctrl+C / Ctrl+V | P2 | 复制到剪贴板（应用内）、粘到视图中心的空位 / 另一层 / 另一个方案 | S24e |
| U11 | 使用空间（衣柜门 / 抽屉 / 餐椅拉开 / 床边通道） | P2 | 选中时画一圈半透明「要留出来的地方」；被别的家具占了 = 黄 | 候选 |
| U12 | 高家具挡窗 | P2 | 家具高过窗台、挡在窗前 → 黄色提示（不是红：挡窗不是「放不下」） | S24f |

**刻意排除**：家具风格推荐 / 自动布置（AI 摆放）、实时协作、移动端触屏手势（单文件桌面浏览器是目标形态）。

## 3. 实现顺序

S24a（U1–U4：先把「放得下」答对、把看得见的缺陷修掉）→ S24b（U5–U7：摆的手感）→ S24c（U8：方案）→ S24d（U9）。
U10–U12 记作候选（U10、U12 随后做成了 S24e、S24f）。每一步照旧：先写应当红的断言 → 修 → bench 三入口 → E2E → calib md5 → ui-gate（改了提示行 / 面板就显式重拍并量差异包围盒）。

**落地（2026-10-26）**：S24a（U1–U4）、S24b（U5–U7）、S24c（U8）、S24d（U9）、S24e（U10）、S24f（U12）完成，规格与门禁读数见 `docs/design/home-v2.md` §S24；
做的过程中当场修了 2 个旧 bug（#93 切到没存过家具的户型时带过去上一份的家具、#94 目录重建丢搜索词）；S24e 顺手修了笔记本宽度下 3D 视图顶栏折成两行、
3D 里点目录卡片新加的件落在画面外。U11（使用空间）仍是候选。
