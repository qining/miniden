# R9. UI 整体风格（现状盘点 → 设计方向）

日期：2026-09（研究/提案）· 服务：UI 重构（S 系列，与 E1 模块化并行）

## 1. 现状盘点（2026-09 截图实测，v3.9）

主屏（2D 视图，`planner.html` 默认加载）：

```
┌ 顶栏: 「家具规划器 2室2卫 · v3.9」 | [2D平面|3D俯瞰|室内视角] | 编辑墙体 |
│        量尺寸/清除 | [cm|英尺] ‖ 底图对照 | 原户型图 | 导出图片 | 导出布局 | 导入布局
├ 左: 家具目录(可收起) ─ 搜索框 / 分类折叠节 / 2 列卡片网格(缩略图+名称+尺寸+绿价) / 自定义家具表单
├ 中: 2D 平面图 ─ 深色画布、白墙线、蓝窗、门弧线、房间标注(名+cm尺寸)、底部操作提示
└ 右: 属性/清单 ─ 选中项属性 / 采购清单(USD/CAD 切换) / 底栏「采购 N 件 · 合计约 US$X」
```

**风格定性**：深藏青「pro-tool」风（≈#161a21 底），功能完整、密度高、
一致性好；**但**：
- 12KB 手写 CSS，**无 design token**（颜色/圆角/间距散落硬编码）
- 字体 = 系统默认（中文渲染依赖平台）；字号无 scale
- 按钮三种样式混用（实心蓝/描边/朴素文字）；圆角 4-8px 不统一
- 「v3.9」「家具规划器」是内部措辞（产品名还没上 UI——命名已定 MiniDen）
- 无焦点环/键盘提示；无 dark/light 切换（只有场景日夜）

## 2. 竞品风格坐标（2026-09 抓取对照）

| 产品 | 风格 | 要点 |
|---|---|---|
| **Planner 5D** | 亮色 consumer | 白底 + 绿网格 + 绿色轴号；极简线性图标顶栏；渐变蓝绿 CTA（"Training session"）；橙色头像。**chrome 完全退到内容后** |
| **HomeByMe** | **渲染即产品** | 营销/产品画面 = 全屏暖调 3D 渲染（米白+木色+柔光），chrome 几乎为零（角落白 logo）。**暖调渲染 + 极简 = 其视觉身份** |
| **酷家乐** | 深色 pro（面向设计师） | 左栏多 tab（灵感库/素材库/我的/深化），高密度面板；深色蓝调 chrome |
| **MiniDen（现状）** | 深色 pro（面向消费者） | 见 §1——与酷家乐同族，但密度为「自己家」服务（1 个户型，不是项目库） |

**坐标结论**：consumer 阵营（P5D/HBM）亮色为主；pro 阵营（酷家乐/Blender/Figma）
深色。MiniDen 的用户是**消费者**，但核心场景是**精度敏感**（放不放得下、
差几厘米）——深色让暖调家居渲染「发光」（像画框衬画），亮白底则让
3D 渲染显得平淡（HBM 靠营销摄影解决亮底问题，我们没有那个预算）。

## 3. 方向提案：**Warm Dark（暖调深色）**

**保留深色**（身份延续 + 衬渲染），但把「冷灰蓝 pro」调成「暖调高级」：

1. **底色变暖**：冷蓝灰 `#161a21` → 暖炭黑 `#191715` / `#201d1a`
   （与场景里的深木地板/暖光同色系，chrome 和内容不再「两个世界」）
2. **一个 accent**：现在的蓝+绿双色收成一个主 accent（暖琥珀/木金
   `#d9a05b` 系，或保留蓝——二选一，**不能双 accent**）；
   价格绿保留为 semantic success（它已经工作得很好）
3. **Typography**：系统栈（不引字体文件——单文件纪律）
   `-apple-system, "PingFang SC", "Segoe UI", sans-serif`；
   scale 12/13/14/16/20，字重只用 400/600；数字（尺寸/价格）用
   `font-variant-numeric: tabular-nums`
4. **Spacing/圆角统一**：4/8/12/16/24px 五档；圆角只两档
   （控件 6px / 卡片 10px）；1px 分隔线用 `--border` token 而非各写各的
5. **深度**：面板单层 elevation（1px border + 微阴影），不做多层叠加
   （2D/3D 画布是主角，chrome 不要抢光）
6. **图标**：现有文字按钮为主，保持（中文按钮比图标自明）；
   未来加图标用 20px 网格 / 1.5px 描边线性体（不引图标库，手写 ~20 个内联 SVG）
7. **品牌位**：顶栏左侧「家具规划器」→ **MiniDen**（产品名 + 可选 迷你窝 副标），
   版本号移到关于/导出里——版本号不是用户信息
8. **双主题**：v1 **只做 dark**（identity 明确）；token 化之后
   light 是「换一套变量值」的事，归 v2

```css
:root{
  /* 色：暖炭黑阶 */
  --bg-0:#141210;  --bg-1:#1b1815;  --bg-2:#232019;  --bg-3:#2c2822;
  --text-1:#ece7df; --text-2:#a89f92; --text-3:#6e675e;
  --border:#332f29;  --accent:#d9a05b;  --accent-hover:#e6b273;
  --ok:#5cbf72;      --warn:#e0b341;    --err:#e06c5a;
  /* 间距/圆角/字号/动效 */
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px; --sp-6:24px;
  --r-1:6px;  --r-2:10px;
  --fs-1:12px; --fs-2:13px; --fs-3:14px; --fs-4:16px; --fs-5:20px;
  --dur:120ms; --ease:cubic-bezier(.4,0,.2,1);
}
```
（具体色值在实现时用 canvas 取色脚本对实拍照片校准，AGENTS §8.3 的方法——
不凭感觉。）

## 4. 组件清单（UI 重构的工作面）

顶栏（segmented 视图切换/单位切换/工具按钮组）、目录面板（卡片/搜索/
分类节/自定义表单）、属性面板（选中项编辑/灯光色温亮度滑杆/门窗参数）、
采购清单（币种切换/行项/合计）、对话框（光追画质/底图导入）、
提示条（底部操作提示）、toast、focus/键盘体系。
每项 = 「现状截图 + token 化 + 行为断言」（验收见 R10）。

## 5. 执行顺序建议

1. **token 先行**（半天）：CSS 变量落地 + 全量替换硬编码值
   ——这一步**不改任何视觉**（旧色值原样进 token），纯重构，
   用 R10 的黄金截图证明「零视觉变化」
2. **换值**（分 2-3 次小步）：暖底 → accent 收敛 → 字体/间距微调，
   每步跑 R10 验收
3. **品牌位 + 组件精修**
