# R5. 编辑器 UX（墙/门/窗编辑、吸附、undo/redo、多户型）

日期：2026-09（研究）· 关联 roadmap S2/S3、ADR-0005

## 1. 竞品编辑模式（调研汇总）

| 产品 | 墙体模型 | 吸附 | 修正环节 |
|---|---|---|---|
| 酷家乐 | **对象式墙**（墙是带厚度的实体，门窗是墙的「子件」）；CAD 导入后「自动读取信息并匹配比例尺」，多户型弹选择框 | 「模型吸附 CAD 底图线条」功能（导入 CAD 作底图时） | 检查生成结果是否完整/尺寸正确，可先关底图 |
| Planner 5D / Floorplanner | 对象式（wall 对象 + 门/窗挂件） | 网格+墙端点+角度（15° 步进） | 底图 1:1 标定后描摹 |
| **MiniDen 现状** | **段式**（WALLS = 线段数组，T 型口咬合、门垛联动——111 断言保护） | 屏幕像素吸附半径（随缩放收缩）+ 角度/网格 | 手工精修（我们的强项） |

**段式 vs 对象式**：
- 对象式（竞品主流）：墙=实体（厚、长、位置），门/窗挂墙上（`wallId+pos`）
  → 拖墙整体移动，门窗跟随；交互直观，**天然对应 Project 文档**（ADR-0005
  的 `doors:[{wallId,pos,width}]` 就是对象式语义）
- 段式（现状）：几何精确控制强（任意角、咬合），但「墙」是隐含的（相邻段推断）
- **MiniDen 判断**：**存储用对象式**（wall 实体 + 子件，= schema v1），
  **几何求值用段式**（wall 实体展开成现有 WALLS 段管线，2D/3D 渲染零改动）。
  即：文档层升级，渲染层不动——风险最小。弧墙 = wall 实体的 `geom:arc`
  （ADR-0002），展开成段链供渲染、展开成弧供 SVG path A。

## 2. 吸附（保持并扩展）

- 现有：端点/中点/平行对齐，**屏幕像素**阈值（AGENTS §8.2：随缩放收缩、
  点击 vs 拖动 ≥5px）——保持
- 新增（服务 S7 图片描摹）：同一吸附框架多挂一个「图像特征线」数据源
  （R2 的 OpenCV 输出）；数据源可插拔（CAD 导入的段 / 图像 Hough 线 / 底图栅格）

## 3. undo/redo（设计建议）

Project 文档 = 单个 JSON（KB 级）→ **快照环**是最优解（命令模式的复杂度
不划算）：
```
ops 提交 → 序列化 doc → 压入 ring buffer（容量 50，~5MB 内存上限）
undo = 弹栈回退；redo 栈同理
节流：连续拖动只在 pointerup 压一次（拖动中不压）
```
- 与 IndexedDB 持久化（E10）天然配合：每次 autosave 的快照可直接复用
- 跨设备/云同步（若做）：快照即「版本」，可存版本历史（nice to have）

## 4. 多户型管理

- Project 文档 = 保存单位；`localStorage`/IndexedDB 里 `projects: {id: doc}`
- UI：项目切换器（顶栏下拉）+ 新建/导入/导出（JSON）+ 删除
- 当前内置户型 = **第一个种子项目**（schema v1 迁移产物，可编辑可另存）

## 5. 窗户交互（S2 设计要点）

- 「选墙放窗」：点墙（段命中）→ 沿墙出现滑轨（pos 0..1）→ 拖出宽度
  （默认 122cm）→ 属性面板（窗台/过梁/款式/框色，模式仿现有灯具色温面板）
- 2D 符号：白窗带 + 款式线型（推拉=双竖线、内开=弧、固定=单线）
- 3D：框=型材截面挤出、玻璃=transmission、内开扇=旋转 Group
  （§5.4.7 规矩：Group 只转向，避免复合欧拉角）
- 弧墙上的窗 = 沿弧的 pos 映射（expand 弧链后取弧长参数）——S2 的边角场景，
  第一版可先只支持直墙，弧墙窗标「暂不支持」
