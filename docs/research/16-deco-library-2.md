## 0. 摘要

S26 把「选一件东西 → 换材质」这条路打通了，在**单个对象**上已经够用。S27 要解决的是另外两件事：

1. **「在哪看就在哪改」还没做到。** 材质的效果只在 3D 里看得到，但在 3D 里点任何东西都选不中（实测见 §1），用户只能在 2D 和 3D 之间来回切。
2. **「一间屋子 / 整套房子看起来协调吗」没有工具。** 墙面、地面、门、柜、五金要逐件去配；房间收边（踢脚线、护墙板、天花）和五金这些决定整体观感的元素都还没有。

| 级别 | 内容 |
|---|---|
| **P0** | ① **3D 点选**（俯瞰和室内都能点地面、墙面、天花、洁具、门窗、柜体，悬停描边）；② **踢脚线**（高度 × 颜色，按房间设）；③ **天花颜色**（按房间设）；④ **五金色**（按房间设一次，作用于龙头、把手、拉手、淋浴边框）；⑤ **整屋配色**（6 套，可预览，套用算一步撤销）；⑥ **M04 修复**（房间范围按墙收边，见 §7） |
| **P1** | 护墙板 / 墙裙（3 种样式 × 2 种高度）、吊柜（含双色柜）、镜子形状与镜柜、淋浴玻璃与边框、马桶圆形 / 加长型、**装修用量**（写进清单，不计价）、吸管（复制材质，Alt + 点）、墙砖填缝色、浴缸配淋浴屏、门把手样式、S09 改口径（「错缝」做成地面的子行） |
| **P2** | 石膏线 / 顶角线、天花木饰面、文化石 / 砖墙、艺术漆 / 微水泥墙面、漆面光泽、门套 / 窗套 / 窗台板颜色、竹 / 软木地板、拼块地毯、过门石、角缸、爪脚浴缸、长虹玻璃、**装修外观跟着方案走**（继续只研究，不实施） |

**体积**：估计 +110–170KB。现在用掉预算的 93.2%（app.html 1775KB / 1904KB）。建议把预算上调到约 2.10MB，dist 相应上调到约 5.05MB。

**分包顺序**：S27a 3D 点选 + M04 → S27b 房间收边（踢脚线、天花、护墙板）→ S27c 五金 + 卫浴细节 → S27d 整屋配色 + 装修用量 + 吸管 → S27e 吊柜。

## 2. 范围与排序

**怎么读**：「外观」= 属于装修；「外观 + 占地」= 属于装修，但改完会改变碰撞判断；「结构」= 属于改户型。

### 2.1 P0

| # | 项 | 房主为什么需要它 | 真实世界的规格 | 归属 |
|---|---|---|---|---|
| ① | **3D 点选** | 材质的效果只在 3D 里看得到。S26 复核里每一条主路径都要在 2D 和 3D 之间来回切：在 2D 点墙、到 3D 看、看完再回 2D 改。这是「看起来怎样」这条路上最大的一块摩擦 | — | 交互 |
| ② | **踢脚线** | S26 加了墙砖和墙纸以后，3D 里墙脚没有收口，看起来像没装修完（review-s26-r1 §5）；踢脚线也是房主下单时一定会被问到的一项 | 高 6 / 8 / 10 / 12 cm（北美常见 3¼–5¼″，约 8–13cm）；颜色：跟墙 / 白 / 跟门 / 黑 / 跟地面，加公共色板；样式：平板、带一道线条（P1） | 外观（3D 里画一条，不进碰撞） |
| ③ | **天花颜色** | 室内视角里天花占画面的 1/3；深色墙配白天花，还是整间同色（color drenching），是近两年很常见的问题 | 白（缺省）/ 跟墙 / 公共色板 | 外观 |
| ④ | **五金色** | 真实装修里「五金统一用什么颜色」是一个决定，不是十几个；一次设好，比逐件去改更省事，也更像真实的选择过程 | 铬、拉丝镍、哑光黑、拉丝金 / 黄铜、古铜 | 外观（按房间设，作用于龙头、门把手、柜子拉手、淋浴边框、毛巾杆） |
| ⑤ | **整屋配色** | 选项多了以后，「从零开始配」门槛很高；成套方案让新手 2 下就能看到整套效果，再在这个基础上微调 | 6 套（research/15 §2.12）：每套包含地面、墙、强调墙、门、柜、台面、五金、踢脚线、天花 | 外观 |
| ⑥ | **M04：房间范围按墙收边** | 在不规则房间里，单面墙会被拆成上百段，名字也没有意义；而个人户型（用户自己的房子）最大的那个房间正好是这样 | — | 结构侧的修复（结论见 §7） |

| 项 | 理由 | 规格 |
|---|---|---|

| 吸管 | 「厨房和卫生间用同一种砖」「门和柜同色」是常见需求；S26 已有的「这套房子已用」能解决一部分，吸管更直接 | Alt + 点一个对象 = 复制它的材质，再点另一个 = 粘贴；或者在检视面板的材质行上加一个「⧉ 复制给…」 |

| 门把手样式 | 和五金色一起做 | 长杆 / 圆球 / 隐形 |
| S09 改口径 | 「错缝」现在是独立的材质（「浅色白橡 1/2 错缝」），但它其实是铺法 | 结论见 §7 |

## 3. 信息架构

### 3.1 3D 点选（P0 ①）

- **范围**：只在「装修」分区里，3D 俯瞰和室内视角都可以点选。「摆家具」分区在 3D 里的行为不变（拖家具）；「改户型」分区在 3D 里仍然是只读。
- **点到什么选什么**（射线命中的第一个面）：

  | 点到 | 选中 |
  |---|---|
  | 地面 | 房间 |
  | 墙的室内一侧 | 这面墙（单面墙），和 2D 里点墙内侧同一个对象 |
  | 天花（只有室内视角能点到；俯瞰视角掀了顶，没有天花） | 这个房间的天花 |
  | 洁具 / 门 / 窗 / 自带厨房 / 台面 | 对应对象 |
  | 家具 | 不响应（和 2D 装修模式一致：家具「看得见、点不到」），提示「家具在『摆家具』里改」 |

- **悬停**：命中的面描边（琥珀色、半透明），光标旁边出一个小标签，例如「卧室1 · 上墙」「马桶」。
- **视角**：选中后不移动相机；检视面板和左栏选择器照常工作，悬停预览直接在 3D 里生效。
- **单击和拖动的区分**：3D 里左键拖动空白处 = 转视角。按下到松开移动不超过 5px 才算点选，和 2D 一样。
- **室内视角**：双击地面仍然是「走过去」；单击 = 选中。新用户可能会误触，所以在提示行加一句：「单击 = 选中 · 双击 = 走过去」。
- **#calib**：只影响 3D，不碰 calib 视图。

### 3.2 房间收边：踢脚线 / 天花 / 护墙板

在房间的检视面板里，紧接「墙面 / 墙砖」之后加三行材质行：

```
房间 · 卧室1 · 21.4 m²
地面       [▦] 深烟熏橡木 · 直铺 ▸
墙面       [■] 白墙 · 整个房间 ▸
墙砖 / 墙裙 [  ] 不贴 ▸        ← 选择器里加两个页签：墙砖 · 护墙板（一次只能用一种）
踢脚线     [▬] 白 · 8cm ▸     ← 子行：高度 6 / 8 / 10 / 12 · 样式 平板 / 线条
天花       [□] 白 ▸           ← 选项：白 / 跟墙 / 色板
五金       [●] 拉丝镍 ▸        ← 只在有洁具、门或柜的房间里显示
窗帘 ……
```

- 护墙板和墙砖放在同一行里二选一：两者在真实装修里都是「墙的下半截」，不会同时用。
- 单面墙的检视面板也加「踢脚线」「护墙板」两行，选项多一个「跟房间」。
- 1440×900 下，选中房间时面板要在一屏之内：新加三行（每行 46px）大约让面板从现在的满屏多出约 130px。解决办法：把「铺贴方向」和「这个房间的墙（N）」收进各自材质行的展开区，只在需要时显示。

### 3.3 五金色（P0 ④）

- **作用范围**：一个房间设一次，这个房间里的龙头、门把手（门在两个房间之间的，取门开向那一侧的房间）、柜子拉手、淋浴边框、毛巾杆（如果有）都跟着变。
- **单件例外**：在单个洁具或门上也能单独设，写「跟房间（拉丝镍）/ 单独设置」，和单面墙同一套逻辑。
- **2D** 不表现五金色，只在 3D 里看得到。

### 3.4 整屋配色（P0 ⑤）

- **入口**：
  - 装修左栏最上面加一张卡片「☀ 整屋配色 ▸」，排在「房间」列表之前；
  - 检视面板空状态（什么都没选时）加一个链接「试一套整屋配色」。
- **选方案**：点了以后，左栏换成**方案选择器**（和材质选择器用同一个外壳）：6 张卡片，2 列 × 3 行；每张卡片上是程序生成的小样（地面、墙、强调色、门、五金几块色块拼在一起，不用图片）。
- **预览**：悬停一张卡片 = 整套房子在 2D 和 3D 里同时预览，不写入文档。
- **套用**：点卡片以后，下面出现两个分段选项：
  - 范围：全屋 / 只这个房间（只有选中了房间时才有这一项）；
  - 方式：覆盖所有设置 / 只填没设过的。

  然后点「套用」按钮才写入。整次套用算**一步撤销**，toast 写明「已套用『北欧浅木』到 6 个房间 · ⌘Z 撤回」。
- **套完以后**：每一项都是普通设置，可以单独再改；方案本身不保存成「绑定」。这样做简单、可预期，也不需要「方案和手改冲突时怎么办」这类规则。
- **强调墙**：方案里的强调墙只在「全屋 + 覆盖」时才设，落在每个卧室床头那面墙上。判断床头墙依赖家具，不可靠，所以缺省给**每个卧室最长的那面实墙**，并在 toast 里说明「强调墙放在了各卧室最长的墙上，可以在墙上单独改」。

### 3.5 吸管（P1）

- 装修里按住 Alt 时光标变成吸管；Alt + 点一个对象 = 吸取它的材质，并在光标旁显示「已吸取：墨绿涂料」；接着点同类对象（墙 → 墙，地面 → 地面，柜 → 柜）就写入，每次写入一步撤销；Esc 退出吸管。
- 2D 和 3D 都可以用。
- 不支持跨类粘贴（比如把门色粘到墙上），提示「只能粘到同类」。

### 3.6 装修用量（P1）

- 清单页签里，「地面用量」那一节扩展为「装修用量（按面积，不含损耗、不计价）」，按材质汇总：
  - 涂料：L，按 2 遍；
  - 墙纸：卷；
  - 墙砖：m²；
  - 踢脚线：m；
  - 护墙板：m²。
- 在 CSV 和「复制清单」里也带上这一节。

## 4. 不做清单

| 不做 | 理由 |
|---|---|
| research/15 §4 的全部内容：品牌色号 / SKU / 建材价格、照片贴图、用户上传材质、AI 配色、铺贴排版和损耗精算、跌级吊顶、定制柜体内部格局、型材和玻璃性能参数、拼花设计器 | 理由不变 |
| 整屋配色的「保存我的方案」/ 方案编辑器 | 先验证 6 套预设够不够用；需要的话，以后跟「装修外观跟着方案走」一起做 |
| 3D 里拖动洁具、改尺寸 | 3D 点选只做「选中 + 换外观」；移动仍在 2D 做（和「改户型只在 2D」是同一个口径） |
| 五金的单件样式库（每种龙头、每种拉手各自的造型） | 颜色决定大部分观感，样式是施工 / 选品细节 |
| 灯槽、吊顶造型 | 施工域 |
| 自动判断「床头墙」 | 依赖家具摆放，判错的代价是用户困惑；只用「最长的实墙」这一条可解释的规则 |

## 5. 体积估算

| 项 | 估算 |
|---|---|
| 3D 点选（射线命中到对象的映射、悬停描边、标签） | 15–25KB |
| 踢脚线 / 天花 / 护墙板（3D 生成、材质行、选择器页签） | 25–40KB |
| 五金色（作用到各种模型的材质替换、继承逻辑） | 15–25KB |
| 卫浴细节（镜子形状、镜柜、淋浴玻璃与边框、马桶圆 / 加长、浴缸淋浴屏） | 20–30KB |
| 吊柜 + 双色柜 | 15–25KB |
| 整屋配色（6 套数据 + 方案选择器 + 套用逻辑） | 8–12KB |
| 装修用量、吸管 | 8–12KB |
| **合计** | **约 +110–170KB** |

**建议**：app.html 预算从 1.904MB 上调到约 **2.10MB**，dist 从 4.834MB 上调到约 **5.05MB**。
**理由**：全部是用户明确要求继续做的功能；现在只剩 129KB 余量，装不下 P0 + P1。上调幅度和 S26 相当。

## 7. 延后项的结论

| 项 | 结论 | 理由与做法 |
|---|---|---|
| **M04 房间多边形漏出墙外** | **这一轮修（S27a，P0）** | 个人户型的「客厅 / 餐厅」轮廓有 403 个顶点、被拆成 139 面墙，选中的墙名字是「上墙 72」（`s27-me-living.png`）。单面墙、踢脚线、护墙板、装修用量都依赖「这个房间有哪几面墙、各多长」；房间轮廓漏出去，这四项在用户自己的房子里都会出错。<br>**做法**：识别房间范围时只沿墙、窗、门洞的边走；两个顶点之间小于 5cm 的合并；共线的边合并。识别出来的轮廓如果明显碰到了别的房间（和另一个房间的名字位置重叠），提示「这个房间没有被墙围起来：在改户型里补一段墙或门洞」，不静默接受。<br>**验收**：个人户型的客厅「这个房间的墙」应该在 15 面以内；示例户型不变 |
| **S09 错缝做成了独立材质** | **改口径（P1，放进 S27b 一起做）** | 「错缝」是铺法，不是材质：现在「浅色白橡 1/2 错缝」和「浅色白橡 直铺」是两个色块，用户换铺法要回到选择器里另找一格。<br>**做法**：地面检视面板「铺贴方向」那一行旁边加「铺法：直铺 / 错缝 1/2 / 错缝 1/3」（只对板材和矩形砖显示）；旧档里的错缝条目照常读出来，显示时映射成「材质 + 铺法」。地毯和水泥不显示「铺贴方向」（QA S09 顺带提到的问题） |
| **S13 剩下的两项** | **左栏右移 24px：这一轮修；自定义颜色在矩阵外：改口径，维持现状** | 右移 24px 是看得见的错位，修起来便宜（选择器打开时，不论左栏收起与否，一律从左边缘开始）。<br>「＋ 自定义颜色…」单独占一行，比塞进矩阵最后一格更好找，而且矩阵每行长度不一，塞进去反而不整齐。把 materials §4.1 的说法改成现在的样子即可 |
| **S14 壁挂马桶需要识别假墙** | **继续延后，同时改口径** | 「有没有假墙」需要识别马桶背后有没有一道薄墙，2D 判断容易误报。<br>**改口径**：选壁挂式时，检视面板始终写一句说明「壁挂马桶要在墙前做一道 12–20cm 的假墙放水箱 → 改户型里画一段薄墙」；2D 里水箱的虚线框一律画在马桶背后，不再根据「有没有假墙」描黄。这样就不需要识别了 |

## 8. 这份研究没有覆盖到的

- 3D 点选在室内视角下的手感（单击和双击怎么区分、误触率），这台机器的无头环境出不了室内画面，需要在实现后用真实 GPU 验证。
- 整屋配色 6 套的具体色值沿用 research/15 §2.12，没有再做比较和调整。
- 吊柜和窗、油烟机、冰箱在高度上的冲突，只提了方向，没有逐条列规则。
- 个人户型其他房间都还没识别范围，只看了客厅这一间的 M04 现象。
