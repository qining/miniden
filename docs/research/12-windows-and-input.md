# 12 · 窗户（加窗 / 墙换窗）与键鼠操作统一：UX gap 研究（2026-10-25）

> 触发：用户 2026-10-25 ——「1.『添加窗户』与『墙面窗户替换』功能：看一下有没有大家通常会要求、比较常用的功能现在还有缺失
> （包括窗户的样式等），看看是否存在 UX 上的 gap。2. 快捷键操作统一：目前 UI 里面鼠标、键盘的快捷键操作，在不同模式下可能还有些
> 不太统一，需要统一成一种比较直观的方式，可以参考一些 2D 或 3D 游戏的用户输入交互设定。」
> 方法：逐个入口读代码盘点现状（每条带代码位置）→ 对照常见户型工具与窗户常识（北美 + 中国）找 gap →
> 键鼠按「模式 × 动作」列全表找冲突 → 对照游戏与设计工具定一套规则。调性仍按 ADR-0006：轻量、homeowner 主路径、不做施工图。

## A. 窗户

### A.1 现状（事实）

| 面 | 现状 | 证据 |
|---|---|---|
| 开窗入口 | **没有「加窗」工具**。两条路：①「画墙」工具把类型切到「玻璃/窗」，一段一段画（墙 → 切类型 → 窗 → 切回 → 墙）；②选中一段墙，「类型」下拉改成「玻璃/窗」——**整段**都变成窗 | `#wtoolSeg`（无窗工具）· `setSegType` → `winFromWall` |
| 在一面墙中间开一扇 1.2m 的窗 | 做不到：要先把墙删掉、重画成三段。没有「拆分墙段」 | 同上；全文无拆段入口 |
| 加门 | 同一个缺口：「加门」只认已有的门洞 / 开口段（「请点击一个门洞/开口（可先用画墙工具画一段类型=门洞的墙）」） | `wallEditDown` 的 `tool==='door'` 分支 |
| 窗台高 / 窗高 | 文档里有 `sill` / `head`，**界面改不了**；只有「普通窗 / 落地玻璃」开关（67cm / 225cm ↔ 0 / 层高） | `#wWinFull` 处理器；`pushUserWindow` 缺省 0.67m / 2.25m |
| 宽 | 「长 + 改这段」：中心不动两端对称伸缩；**两侧相邻墙段不跟着变**——窗伸进相邻的墙里（2D 玻璃线压在墙上、3D 窗台 / 过梁与墙体重叠），缩短则留缝 | `applyLenEdit` 的 `isWin` 分支（只按 `wallId` 宿主夹取，画出来的窗 `wallId` 都是 null） |
| 位置 | 拖窗身 = **自由平移**（离开墙线）；方向键 = 平面方向平移（同样离开墙线）。门是「沿墙滑动、两侧门垛跟着伸缩」（`doorLinkage`），同一类东西两种行为 | `wMove` 拖动；`keydown` 的 `kind==='w'` 微调分支 |
| 款式 | 4 种循环按钮：固定 / 推拉 / 平开 / 上悬；平开只有对开一种（无左右开）；推拉只有 2 扇 | `WS_NAMES` · `#wWinStyle`；3D `buildLevelStatic` 窗分支 |
| 框色 | 只有黑钢框 ↔ 白框两档 | `#wWinFrame` |
| 玻璃 | 只有一种透明玻璃（`glass` 不透明度固定） | 同上 |
| 窗帘 | 有（S21） | — |

### A.2 用户通常会要什么（对照）

- **户型工具的放窗流程**（RoomSketcher 帮助中心 / Sweet Home 3D 用户论坛）：从窗库选一扇 → **点墙就放上去、按住拖动沿墙移动**；
  属性里**直接输入宽、高、离地高（Height Above Floor = 窗台高）**，窗顶 = 离地高 + 窗高；拖窗两侧的大箭头改宽；
  吸附（magnetism）帮你贴到墙里，按住 Alt 临时关掉吸附、方向键微调。
- **北美住宅最常见的窗型**：单提拉 / 双提拉（single-/double-hung）最常见（This Old House、Consumer Reports）；
  西部较新的房子多平开（casement）；推拉（slider）常见于地下室、厨房水槽上方、卫生间；景观窗（picture，固定不开）；
  上悬（awning）、凸窗（bay/bow）在 2024 年一项 1000 户调查里各有约四分之一的人选。
- **中国住宅的窗**：推拉、平开（中高层 / 高层**禁外平开**，以内平开为主）、**内开内倒**、飘窗、落地窗；
  **住宅窗台宜 0.9m**（低于 0.9m 要加防护），厨房宜 0.9–1.2m（台面上方），**卫生间宜 1.2–1.5m**；
  常用洞口宽 1200 / 1500 / 1800 / 2100 / 2400mm，高 900–2100mm。
- 两边都说明一件事：**窗台高、窗高与「点墙开窗 + 沿墙挪」是一等公民**；款式至少要覆盖「提拉」（北美）与「内开内倒」（中国 / 欧洲）。

### A.3 Gap 清单

P0 = 用户点名的两个入口（加窗 / 墙换窗）本身走不通或会出错；P1 = 常用、直接影响「看起来对不对」；P2 = 有价值、可以晚一步。

| # | Gap | 优先级 | 方案要点 | 路线图 |
|---|---|---|---|---|
| W1 | 没有「加窗」：不能在一面墙的任意位置开一扇指定宽度的窗 | P0 | 编辑工具条新工具「加窗」：悬停在实墙上预览窗的位置与两头到墙端的距离，点一下 = 把这段墙拆成「墙 \| 窗 \| 墙」（同墙厚；内置墙 = 隐藏原段、换成三段用户段）；窗中心吸到墙段中点（Alt = 不吸）；两头各留 ≥ 5cm 墙，放不下就夹到放得下并说明；挂在这段墙上的点位按位置重挂到新墙段（落在窗里的去掉并说个数）；点到已有的窗 = 选中；一步撤销 | S22a |
| W2 | 「墙换窗」只能整段换 | P0 | 选中一段墙时工具条多一个「在这段开窗」：在墙段中点开一扇工具条宽度的窗（墙段比窗短 = 整段换成窗，就是原来的「类型 → 玻璃/窗」）；下拉的整段转换保留（窗墙 / 玻璃幕墙就是要整段） | S22a |
| W3 | 窗台高、窗高改不了 | P0 | 窗工具条加「窗台高」「窗高」两个数值框（cm）；窗顶最高到天花下约 8cm（与 3D 窗头夹取同一个数），否则拒收并说明；「落地」= 窗台 0、窗高到天花 | S22a |
| W4 | 改窗宽时窗伸进 / 离开相邻墙段 | P0 | 改宽 = 中心不动、两侧共线墙段跟着伸缩（与门的联动同一套 `doorLinkage` 机理：端点跟随 + 墙垛最短保留）；放不下夹到最大并说明 | S22a |
| W5 | 拖窗 / 方向键会把窗拖离墙线 | P0 | 拖窗身 = **沿墙滑动**（两侧墙段跟着伸缩），拖端点 = 改宽（另一端不动）；方向键 = 沿墙 1cm、Shift 10cm（按 S23 的统一步长）；提示里写「离左端 X · 离右端 Y」 | S22a |
| W6 | 加门同样只认门洞 | P1 | 同一套开洞：「加门」点实墙 = 先开门洞（缺省 80cm）再放门 | S22a |
| W7 | 款式少：没有提拉、内开内倒；平开不分左右、推拉只有 2 扇 | P1 | 款式改下拉：固定 / 推拉（2 · 3 · 4 扇）/ 平开（左开 · 右开 · 对开）/ 上悬 / 提拉（北美单 · 双提拉）/ 内开内倒；每种一个 2D 符号 + 3D 造型 | S22b |
| W8 | 框色只有黑 / 白，玻璃只有透明 | P1 | 框色色板：白 · 黑 · 深灰 · 原木 · 胡桃；玻璃：透明 / 磨砂（卫生间） | S22b |
| W9 | 常用尺寸要自己算 | P2 | 「加窗」工具条的宽 / 窗台高 / 窗高带常用值（北美 24″ / 36″ / 48″ / 60″ / 72″，中国 1200 / 1500 / 1800mm；卫生间高窗台、厨房台面上方的窗台）| S22a（随 W1） |
| W10 | 飘窗（窗前一块抬高的台面）表达不了 | P2 | 窗的可选「飘窗台」：深 / 高；2D 画出台面、3D 一块台座、家具碰撞把它当障碍 | S22c（候选） |
| W11 | 窗格 / 格栅 | P2 | 无 / 田字 / 殖民地格（只是外观） | 暂不做 |

**刻意排除**：凸窗的外立面结构（凸出墙外的那部分墙体）、天窗（没有坡屋顶）、窗的五金细节与开启角度校核、
采光 / 通风面积与逃生窗（egress）规范校核、窗的采购（不在目录里）。

### A.4 设计要点

- **开窗 = 拆段**，不引入「墙上挂窗」的新几何模型：现有的 2D 墙多边形、3D 窗台 / 过梁、房间区域、墙色断点、
  窗帘、穿墙判据、点位宿主全都按「墙段链」读，拆段之后它们**不用改一行**就对。新窗段继承墙厚（`thick` / `wdPx`），
  两头的墙段继承原墙的类型与厚度；内置墙不改常量，走「隐藏 + 用户段」（与删除内置墙同一条路，撤销可逆，`#calib` 不受影响）。
- **沿墙滑动 / 改宽复用门的联动**（`doorLinkage`：共线墙垛的端点跟着窗的端点走、墙垛最短 `STUB_MIN`、范围取交集），
  一份已被 bench 守着的机理，不另写一套。
- **点位重挂**：挂在被拆那段墙上的点位按 `at`（沿墙距离）分到左段 / 右段（右段 `at` 减去偏移），落在窗跨度里的去掉
  （与轮㊳「换类型去掉点位」同一条规则，提示说个数）。
- schema：`WindowStyle` 加 `hung` / `tilt`；窗加可选 `panes`（推拉扇数）、`hand`（平开 / 内开内倒的开启侧）、`frost`（磨砂）——
  全是纯增量可选字段，旧文档照读。

### B.3 参照（游戏与设计工具）

- **The Sims 4 建造模式**：WASD / 方向键移动镜头、Shift 加速；`,` `.` 每次转 45°；**按住 Alt = 自由摆放 / 自由旋转（不吸网格）**；
  PageUp / PageDown 上下楼层；Delete 删除；Ctrl+Z / Ctrl+Y 撤销重做。
- **Figma**：方向键挪 1px、**Shift+方向键 10px**；Shift+拖动旋转 = 15° 一格；按住 Ctrl 临时关掉所有吸附；
  Ctrl+Shift+? 打开快捷键总表。
- **三维编辑器（Blender / Unity / Unreal）**：F = 把镜头对准选中的东西 / 全貌。
- **第一人称游戏**：WASD 走、鼠标看、Shift 跑。

共同的直觉：**WASD 管镜头（或人），方向键挪东西；Shift = 更大一步 / 约束，Alt = 不吸附（自由）；Ctrl/⌘ = 命令**；
一张随时能叫出来的快捷键表。

### B.4 统一方案（一张表 = 唯一事实来源；底部提示与快捷键面板都从它生成）

**规则**

1. **WASD = 镜头**，三个视图一样：平面图 = 平移图纸，3D 俯瞰 = 平移镜头，室内 = 走路；**Shift = 快**（室内 = 跑）。
   **Q / E = 转镜头**（俯瞰 = 绕着转，室内 = 原地左右转）。
2. **方向键 = 挪选中的东西**（平面图 / 俯瞰）：**1cm 一步，Shift = 10cm**——家具、墙、窗 / 门（沿墙）、洁具、点位、整层、底图全一样。
   室内视角没有可挪的选中物，方向键 = 走路（同 WASD）。
3. **修饰键**：**Shift = 约束 / 大步**（拖动 = 锁横或竖；画墙 / 柱 / 台面 / 量尺寸 = 锁 0° / 45° / 90°；旋转手柄 = 15° 一格；
   方向键 = 10cm；[ ] = 15°）；**Alt = 不吸附 / 自由**（拖动、画线、开窗开门、旋转手柄 = 自由角度、[ ] = 0.1°）；
   **Ctrl/⌘ = 命令**（Z 撤销、Shift+Z / Y 重做、**D 复制**）。
4. **旋转**：R = +15°（Shift+R = −15°）、[ / ] = −1° / +1°，作用于家具与洁具；平面图另有圆点手柄；
   **3D 俯瞰里右键拖家具 = 转**（左键拖 = 挪，与平面图一致；Shift+左键拖 = 锁轴挪，不再是转）。
5. **鼠标**：左键 = 选 / 挪 / 画；左键拖空白 = 「抓住场景」（平面图平移、俯瞰绕转、室内转头）；
   右键拖 / 中键拖 = 平移（平面图任何模式都一样，不再弹浏览器菜单）；滚轮 = 缩放（室内 = 前后走）；
   双击地面 = 进室内站到那儿 / 走过去；Shift+点 = 加减选；Shift+拖空白 = 框选（平面图）。
6. **全局键**：Esc 一层一层退（取消正在拖 / 画的 → 取消选中 → 退出当前工具或模式）；Delete / Backspace 删选中（画线时 Backspace 撤一点）；
   Enter 结束画线；**1 / 2 / 3 = 平面图 / 3D 俯瞰 / 室内**，V = 俯瞰 ↔ 室内；**F = 全貌**；**PageUp / PageDown = 上一层 / 下一层**；
   **? = 快捷键面板**。
7. **模式之间不串键**：室内视角里改家具的快捷键一律不作用（K1）；编辑墙体时家具快捷键不作用（已有）。

**对老用户手感的改动**（提交与面板里写清）：复制从 D 改成 Ctrl/⌘+D（D 让给「向右挪镜头」）；家具方向键从 7.6cm 变 1cm、
Shift 从「更细」变「10cm」；墙的 Shift 步长 5cm → 10cm；底图 10 / 2.5cm → 1 / 10cm；画墙的「Shift = 不吸附」改成 Alt
（Shift 改为锁 0 / 45 / 90°）；3D 里 Shift+拖不再转（改右键拖）；旋转手柄 Shift 从「自由」改成「15° 一格」（自由改 Alt）；
[ ] 从 0.5° 变 1°（Alt = 0.1°）。

### B.5 验证

- bench：每条规则在每个模式下各一条断言（按键 → 效果，含「不该有效果」的反例：室内按 D 不复制、编辑墙体按 R 转洁具不转家具……）；
  老断言里按旧手感写的（D 复制、3D Shift+拖转、步长）逐条改写并在提交里列出。
- E2E：真键盘按 PageUp 换层、1 / 2 / 3 换视图、? 开面板、室内按住 D 不复制、3D 右键拖转。
- 面板内容与底部提示从同一张表生成：断言「面板里列的每一条，底部提示与实际行为都一致」（拿表驱动 bench）。
