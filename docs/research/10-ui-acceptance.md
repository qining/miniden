# R10. UI 改动的验收标准

日期：2026-09（研究/规范）· 配套 R9（风格）· 落地时并入 AGENTS.md

**核心问题**：现有门禁（calib md5 / 208 断言）守的是**几何与行为**，
UI chrome 的「看起来对不对」没有机器门禁——改 CSS 改坏了只能靠人眼。
本文件把 UI 验收做成**可重复执行的流程**。

## 1. 五道验收关（每次 UI 改动全跑）

### 关 A：行为断言（已有体系，扩展）

- 重新生成三测试台 → t3d 65 / walledit 111 / tpt 32 全绿
- **新 UI 表面必须加断言**（沿用合成 PointerEvent 手法，AGENTS §3）：
  例：新按钮 → 断言点击后某 DOM 状态/属性变化可观察；
  新面板 → 断言展开/收起后宽度/可见性
- 断言里**不写死颜色常量**（AGENTS §3 教训）——UI 断言只断言
  结构/状态/几何，不断言像素色

### 关 B：calib 不变性（自动）

- `#calib` md5 必须仍是 `1ac26921871db50ef1c055674c10e6e7`
- 机制保证：`body.calib` 锁死旧布局（§5.4.6）→ UI 重构原则上**不可能**
  影响 calib；如果它变了，说明锁被破坏，**立即停**，不是更新基线

### 关 C：黄金截图（**新建**，本次提案的核心）

**`#ui` hash 模式**（新加）：进入指定规范化 UI 状态并冻结（隐藏光标/
时间戳/随机元素），供 headless 截图比对。

首批黄金集（`work/golden/`，每张 = 一个 UI 状态）：

| 状态 | hash | 覆盖 |
|---|---|---|
| 2D 默认（空布局，目录展开） | `#ui:2d` | 顶栏/左右面板/2D 画布 |
| 2D + 选中一件家具 | `#ui:2d-sel` | 属性面板填充态 |
| 3D 俯瞰 | `#ui:3d` | 3D 画布 + 顶栏切换态 |
| 3D 室内（fp） | `#ui:fp` | fp 专属控件（PT 按钮等） |
| 夜间模式 | `#ui:night` | 日夜切换 |
| 英尺单位 | `#ui:ft` | 单位切换全 UI |
| 面板全收起 | `#ui:collapsed` | 折叠 tab |
| 光追画质对话框 | `#ui:dlg` | 对话框样式 |

**比对规则**：
- **本地（开发机）**：像素 diff 比例 ≤0.3% 为 PASS（字体渲染有亚像素抖动），
  超限则输出 diff 图（差异像素标红）供目检
- **CI（ubuntu-latest + Chrome）**：同代码两次渲染 md5 必须一致
  （确定性前提：固定字体/种子/窗口）；黄金基线用 CI 环境生成
- **改样式的 PR**：必须重拍受影响状态的黄金图并在 PR 里贴新旧对比
  ——**黄金图更新是显式动作，不是默认通过**

### 关 D：交互体检（手动，~2 分钟，固定清单）

- [ ] 键盘：Tab 走完整控件环，focus 环可见，Esc 关对话框/取消操作
- [ ] 三视图 × 双单位 × 日夜 = 12 个组合各瞟一眼（重点：文字不溢出、
      数字 tabular 对齐、accent 一致性）
- [ ] 面板拖宽/收起/刷新后恢复（`planner_panels_v1`）
- [ ] 拖家具时顶栏/工具条**不跳动**（定高单行规矩，AGENTS §5.2）
- [ ] 静止时任务管理器 GPU 占用 ≈0（按需渲染没被破坏）

### 关 E：卫生（自动可查）

- [ ] `node --check` 通过；`window.__ERRS` 空（console error/warn 全收）
- [ ] **文件体积预算**：planner.html 增长 ≤ 本次功能合理量
      （经验值：UI 小功能 ≤5KB；超了要说明）
- [ ] **token 纪律**：新增 CSS 不得出现 token 之外的裸色值/裸 px
      （可脚本查：grep CSS 区 hex 值 ∉ token 集合 → 列清单）
- [ ] 中文文案不写死宽度（AGENTS：CJK 宽度坑）；新文案同时想 zh 表达

## 2. 用户报「UI 看着不对」的处理流（AGENTS §10 扩展）

1. **先确认看到的是同一处**：`screenshot({kind:'question'})` / 放大裁剪对照
2. 复现 → 归因（token 错值？组件布局？渲染 bug？）
3. 修复 → 跑五道关
4. **沉淀**：若暴露通用规律（例「某类控件在某场景必炸」）→ 按自我生长
   四步写进 SKILL/AGENTS + 本文的清单

## 3. 明确「不验收」的（避免过度工程）

- 跨浏览器像素一致（只保 Chrome；Safari/Firefox 行为级可用即可）
- 响应式/移动端（v1 是桌面工具；窗口 <1000px 时给「请用大屏」提示即可）
- 动画逐帧验收（只验收动画**起止状态**进黄金集，过程人眼）
- a11y 完整审计（v1 做关 D 的键盘项；WCAG 全项归 v2）

## 落地工作量估计

- `#ui` hash 模式 + 截图脚本 + diff 工具：~半天（Python PIL 或
  页面内 canvas 比对均可；diff 图输出进 work/）
- 8 张黄金基线：~1 小时（含调参冻结变量）
- 合入 AGENTS.md「§2 开发流程」的关卡序列：~10 分钟
