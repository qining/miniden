# home-v2：house 与「放下去会不会挡住什么」（S15–S21 设计文本）

> 来源：`docs/research/11-home-furnishing-gaps.md`（gap 审计）· 多层的架构决定：ADR-0007。
> 每一节 = 一个组件的规格 + 它的验证计划。开工时细化对应小节，落地后在末尾补「门禁读数」。

## 0. 共同口径（所有小节都适用）

- **纯函数进 `src/`，vitest 直接测**：点位遮挡判据、房间区域识别、楼梯几何、楼层的文档变换都不碰 DOM / three，
  分别在 `src/geo/points.ts`、`src/geo/regions.ts`、`src/geo/stairs.ts`、`src/schema/levels.ts`，经 `MINIDEN_GEO` / `MINIDEN` 挂到页面。
- **文档字段一律纯增量可选**，不进 `docToLegacy` 投影；`validate` + JSON Schema 拒非法值（消费端按枚举分支，未知值会渲成隐形件）。
- **`#calib` 逐字节不变**：新视觉元素全部 `!CALIB` 门控；没有新数据时 2D / 3D 与今天逐字节一致 → ui-gate 8/8 不重拍。
- **门禁层次**（每一项都走完）：tsc + lint + format → vitest（纯函数 + schema）→ bench（`t_planbuild` 新增一节，plan-independent，三入口）
  → E2E（真实鼠标 / 键盘 / 刷新，新增或扩展一条流程）→ calib md5 → ui-gate → 视觉目检（2D + 3D 截图放大看）→ 全量 bench + 全量 E2E。
- **断言独立测量**：从几何本身量回去（墙皮距离 = 画出来的半厚、高度 = 宿主台面高 + 偏移、面积 = 鞋带公式对独立构造的多边形），不照抄实现公式。
- **包体预算是棘轮**：这一轮会让 `app.html` 超过 1221KB 的预算；上调时在提交信息里写清楚涨了多少、为什么。

## S15 · 点位家族（电源 / 网络电视 / 水 / 燃气 / 风）+ 被挡住高亮

### 数据

`outlets[]`（S14 的实体）的 `kind` 扩成下表；`host` 加 `floor` / `ceiling` 两种安装面（这两种以 `x / y / rot` 为事实来源，`h` 由安装面决定）。
类型表是 **schema 的数据**（`SCHEMA.Project.POINT_KINDS`），校验与界面读同一份：`validate` 拒「这类点位不能装在这个安装面上」。

| kind | 名称 | 类别 | 可装 | 缺省离地 | 面板（宽×高 cm） | 联数 | 算不算「被挡住」 |
|---|---|---|---|---|---|---|---|
| std / usb / gfci | 普通 / USB / 防水插座 | 电源 | 墙 · 台面 · 台柜 | 30（台面 / 台柜 = 台面 + 15） | 7×11.5 | 1–3 | 算 |
| w240 | 240V 大功率插座（烘干机 / 电炉） | 电源 | 墙 | 76 | 10×12 | 1 | 算 |
| switch | 开关 | 电源 | 墙 | 120 | 7×11.5 | 1–3 | 算 |
| coax | 同轴（有线电视） | 网络 · 电视 | 墙 · 台面 | 30 | 7×11.5 | 1–2 | 算 |
| lan | 网线口（RJ45） | 网络 · 电视 | 墙 · 台面 | 30 | 7×11.5 | 1–2 | 算 |
| supply | 上水（冷热水阀箱） | 水 | 墙 | 110 | 20×15 | 1 | **不算**（洗衣机本来就该站在它前面） |
| drain | 下水（排水立管） | 水 | 墙 | 95 | ⌀5 | 1 | 不算 |
| floorDrain | 地漏 | 水 | 地 | 0 | 10×10 | 1 | 不算 |
| gas | 燃气口 | 燃气 | 墙 | 30 | 8×8 | 1 | 不算 |
| supplyVent | 送风口 | 风 | 地 · 墙 · 天花 | 0 / 30 / 天花 | 25×10 | 1 | 算（挡住就不出风） |
| returnVent | 回风口 | 风 | 墙 · 地 · 天花 | 30 | 50×30 | 1 | 算 |
| dryerVent | 烘干机排风口 | 风 | 墙 | 40 | ⌀10 | 1 | 不算 |
| hood | 油烟机排风口 | 风 | 墙 · 天花 | 210 / 天花 | ⌀15 | 1 | 不算 |
| exhaust | 排风扇 | 风 | 天花 · 墙 | 天花 / 200 | 25×25 | 1 | 不算 |

「算不算被挡住」的口径：**挡住 = 有一件不使用它的东西把它盖住了**。电源、网络、开关、送回风口被沙发 / 柜子盖住是用户要知道的事；
上下水、燃气、排风口前面站着洗衣机 / 烘干机 / 灶台恰恰是正确的摆法，高亮它们只会制造噪音。

### 遮挡判据（`src/geo/points.ts` → `pointBlockers(point, boxes)`）

- 输入：点位 `{x, y, rot, h, host, plateH}`；家具盒 `{id, corners(OBB 4 点), z0, z1, rug, light}`。
- 墙面类（wall / run / fx）：在面板正前方 5–25cm、左右各半个面板宽的一排探点；某件家具的占地包含任一探点，**且**它的高度区间与
  `[h − plateH/2, h + plateH/2]` 有交集（低于面板下沿的矮柜不算、壁挂在面板上方的柜子也不算）→ 挡住。
- 地面类：占地包含点位中心、且家具落地（`z0 ≤ 5cm`，地毯也算 —— 地毯盖住送风口一样不出风）→ 挡住。
- 天花类：永不判。灯具、幽灵件不参与。
- 输出：挡住它的家具 id 列表（界面用它写提示「被「沙发」挡住」）。

### 界面

- 工具条「插座」改名「点位」（`data-t="outlet"` 不变）；类型下拉按类别分组（`optgroup`）；新增「安装面」：自动 / 墙面 / 地面 / 天花（只亮这类点位允许的）；
  联数只对允许多联的类型显示。
- 「自动」：点在台柜 / 台面 / 墙附近 → 照 S14 的吸附；点在房间中间 → 允许装地面的类型落在地上（送风口按最近的墙摆正方向），否则拒放并说明。
- 被挡住的点位：2D 图例变红 + 外圈红色虚线晕 + 悬停提示「被「XX」挡住」。拖家具时实时刷新。

### 验证

- vitest：`POINT_KINDS` 表的自洽（每个类型有名称 / 类别 / 安装面 / 缺省高度）；`validate` 拒非法安装面；`pointBlockers` ≥ 10 个用例
  （沙发挡低插座 / 矮凳不挡高插座 / 壁挂柜在插座上方不挡 / 旋转 45° 的柜子 / 地毯盖送风口 / 地毯在墙面插座前不挡 / 天花永不 / 灯具不参与 / 上下水不判 / 空列表）。
- bench `t_planbuild` 第 20 节：每个类别各放一个（含地面送风口、天花油烟机口），3D 射线打到它；沙发推到插座前 → 图例变红且提示写出沙发名，挪开 → 恢复；
  低矮件不变红；地毯盖送风口变红；洗衣机站在上水前不变红；类型 / 安装面非法组合被拒。
- E2E：`outlet-tool` 扩展「放一件沙发挡住插座 → 图例变红（真实截图 + 颜色读数）→ 拖开 → 恢复」。

## S16 · 房间与地板

- `src/geo/regions.ts`：把墙 / 窗 / 门洞 / 开口 / 柱按真实厚度栅格化（2 英寸一格），从点击点泛洪，追踪外轮廓（Moore 邻域）+ RDP 简化 → 房间多边形；
  从包围盒外泛洪得到「室外」，补集的外轮廓 = 真实的房屋外轮廓（修 G16：L 形房子的地板不再伸到墙外）。面积 = 鞋带公式。
- `rooms[]` 加可选 `poly`（房间轮廓）与 `floor: {mat, angle}`；每层可选 `floorMat`（整层缺省地板）。
- 地板预设表（木地板多色 × 直铺 / 人字拼 / 鱼骨拼、瓷砖多规格、石材、地毯、乙烯基、水泥）；每种一个程序化贴图（**新种子只增不改**），
  UV = 世界坐标（ft）按铺法方向旋转后**烘进几何**（光追只读 repeat / offset、不读 rotation）。
- 工具条「房间」：悬停虚线预览这块区域 → 点选 → 命名（内置户型的房间名固定）、看面积、选地板与方向。
- 验证：vitest（栅格 / 泛洪 / 轮廓 / 简化 / 面积 / 外轮廓，含通用户型 fixture 与合成 L 形）；bench（点房间 → 多边形面积与墙皮围成的独立量一致、
  3D 地板换贴图、2D 有底纹、命名与面积显示、重标定跟着走、导出往返）；E2E（真实点选房间 → 换人字拼 → 刷新还在）。

## S17 · 多层与楼梯

- `src/schema/levels.ts`：`enableLevels / activateLevel / addLevel(above|below, copyShell) / removeLevel / relayout / forEachLevel`，全是文档变换的纯函数（ADR-0007）。
- `src/geo/stairs.ts`：直跑 / L 形 / U 形（中心线 2–4 点 + 宽度）→ 踏步、平台、占地多边形、方向箭头；步数 = 层间高差 / 17.5cm 取整。
- 界面：画布左上角楼层切换条（一层 / 二层 / + 加一层），楼层设置（名称、层高、删除两步确认）；编辑工具条「楼梯」；
  上层显示下层墙线参照（淡）与楼梯虚线 +「下」；3D 叠层、上层楼板开洞、楼板厚度封边；家具 `lv`；采购清单标楼层；导入确认框「导入为新楼层」。
- 验证：vitest（levels 变换往返、标高重排、楼梯几何）；bench（加层 / 切层 / 家具归属 / 楼梯 3D 台阶与开洞射线 / 撤销跨层 / 导出往返 / 删层两步确认 / 内置户型拒加层并说明）；
  E2E（空白 → 画一层 → 加二层（复制外墙）→ 画楼梯 → 3D 看到两层与楼梯 → 真实刷新还在）。

## S18 · 家具贴墙、距离提示、穿墙与门扇遮挡

- 拖动时：家具某条边离墙皮 < 12 屏幕像素 → 贴齐（Alt 按住 = 不吸附）；显示到最近墙面的距离标注（随拖动重画，结束即消失）。

- 验证：`src/geo/placement.ts` 纯函数（吸附 / 距离 / OBB × 多边形 / 扇形）vitest；bench（贴墙后间距 = 0、Alt 不吸附、穿墙变红、门扇变红、挪开恢复）；E2E 真实拖动。
