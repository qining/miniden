# home-v2：house 与「放下去会不会挡住什么」（S15–S23 设计文本）

> 来源：`docs/research/11-home-furnishing-gaps.md`（gap 审计）· 多层的架构决定：ADR-0007。
> 每一节 = 一个组件的规格 + 它的验证计划。开工时细化对应小节，落地后在末尾补「门禁读数」。

## 0. 共同口径（所有小节都适用）

- **纯函数进 `src/`，vitest 直接测**：点位遮挡判据、房间区域识别、楼梯几何、楼层的文档变换都不碰 DOM / three，
  分别在 `src/geo/points.ts`、`src/geo/regions.ts`、`src/geo/stairs.ts`、`src/schema/levels.ts`，经 `MINIDEN_GEO` / `MINIDEN` 挂到页面。
- **文档字段一律纯增量可选**，不进 `docToLegacy` 投影；`validate` + JSON Schema 拒非法值（消费端按枚举分支，未知值会渲成隐形件）。
- **`#calib` 逐字节不变**：新视觉元素全部 `!CALIB` 门控；没有新数据时 2D / 3D 与今天逐字节一致 → ui-gate 8/8 不重拍。
- **门禁层次**（每一项都走完）：tsc + lint + format → vitest（纯函数 + schema）→ bench（`t_planbuild` 新增一节，plan-independent，三入口）
  → E2E（真实鼠标 / 键盘 / 刷新，新增或扩展一条流程）→ calib md5 → ui-gate → 视觉目检（2D + 3D 截图放大看）→ 全量 bench + 全量 E2E。
- **断言独立测量**：从几何本身量回去（墙皮距离 = 画出来的半厚、高度 = 宿主台面高 + 偏移、面积 = 鞋带公式对独立构造的多边形），不照抄实现公式。
- **包体预算是棘轮**：这一轮会让 `app.html` 超过 1221KB 的预算；上调时在提交信息里写清楚涨了多少、为什么。

## S15 · 点位家族（电源 / 网络电视 / 水 / 燃气 / 风）+ 被挡住高亮

### 数据

`outlets[]`（S14 的实体）的 `kind` 扩成下表；`host` 加 `floor` / `ceiling` 两种安装面（这两种以 `x / y / rot` 为事实来源，`h` 由安装面决定）。
类型表是 **schema 的数据**（`SCHEMA.Project.POINT_KINDS`），校验与界面读同一份：`validate` 拒「这类点位不能装在这个安装面上」。

「算不算被挡住」的口径：**挡住 = 有一件不使用它的东西把它盖住了**。电源、网络、开关、送回风口被沙发 / 柜子盖住是用户要知道的事；
上下水、燃气、排风口前面站着洗衣机 / 烘干机 / 灶台恰恰是正确的摆法，高亮它们只会制造噪音。

### 遮挡判据（`src/geo/points.ts` → `pointBlockers(point, boxes)`）

- 输入：点位 `{x, y, rot, h, host, plateH}`；家具盒 `{id, corners(OBB 4 点), z0, z1, rug, light}`。
- 墙面类（wall / run / fx）：在面板正前方 5–25cm、左右各半个面板宽的一排探点；某件家具的占地包含任一探点，**且**它的高度区间与
  `[h − plateH/2, h + plateH/2]` 有交集（低于面板下沿的矮柜不算、壁挂在面板上方的柜子也不算）→ 挡住。
- 地面类：占地包含点位中心、且家具落地（`z0 ≤ 5cm`，地毯也算 —— 地毯盖住送风口一样不出风）→ 挡住。
- 天花类：永不判。灯具、幽灵件不参与。
- 输出：挡住它的家具 id 列表（界面用它写提示「被「沙发」挡住」）。

### 界面

- 工具条「插座」改名「点位」（`data-t="outlet"` 不变）；类型下拉按类别分组（`optgroup`）；新增「安装面」：自动 / 墙面 / 地面 / 天花（只亮这类点位允许的）；
  联数只对允许多联的类型显示。
- 「自动」：点在台柜 / 台面 / 墙附近 → 照 S14 的吸附；点在房间中间 → 允许装地面的类型落在地上（送风口按最近的墙摆正方向），否则拒放并说明。
- 被挡住的点位：2D 图例变红 + 外圈红色虚线晕 + 悬停提示「被「XX」挡住」。拖家具时实时刷新。

### 验证

- vitest：`POINT_KINDS` 表的自洽（每个类型有名称 / 类别 / 安装面 / 缺省高度）；`validate` 拒非法安装面；`pointBlockers` ≥ 10 个用例
  （沙发挡低插座 / 矮凳不挡高插座 / 壁挂柜在插座上方不挡 / 旋转 45° 的柜子 / 地毯盖送风口 / 地毯在墙面插座前不挡 / 天花永不 / 灯具不参与 / 上下水不判 / 空列表）。
- bench `t_planbuild` 第 20 节：每个类别各放一个（含地面送风口、天花油烟机口），3D 射线打到它；沙发推到插座前 → 图例变红且提示写出沙发名，挪开 → 恢复；
  低矮件不变红；地毯盖送风口变红；洗衣机站在上水前不变红；类型 / 安装面非法组合被拒。
- E2E：`outlet-tool` 扩展「放一件沙发挡住插座 → 图例变红（真实截图 + 颜色读数）→ 拖开 → 恢复」。

## S17 · 多层与楼梯（完，2026-10-23）

- `src/schema/levels.ts`：`enableLevels / activateLevel / addLevel(above|below, walls) / removeLevel / relayout / setLevelCeiling / forEachLevel`，
  全是文档变换的纯函数（ADR-0007）。当前层的内容在文档顶层；切到一层只有外壳的楼层（手写 / 旧导出缺内容键）时顶层补上必填的空值。
- `src/geo/stairs.ts`：中心线 2–4 点 + 宽度 → 踏步（每级四角 + 顶高）、平台、占地分块、**外轮廓**（并集：斜接加宽中心线 + 清理）、箭头；
  踏步数 = 层间高差 / 17.5cm 取整（2–40），按梯段长度用最大余数法分给各段；U 形中间那段可以短到 0（双跑楼梯，不分踏步、当平台走）；
  两个平台互相压住、起步 / 收尾那段放不下一级、折回去的急弯（> ~148°）→ null。
- `src/geo/points.ts` `convexClipArea(subject, clip)`：凸的裁任意的（Sutherland–Hodgman）→ 家具占地压在楼梯外轮廓上的面积（> 0.05ft² 才算）。
- 界面：画布左上角楼层条（高的在上；「＋ 加一层」缺省带上本层的外壳 —— 外墙 + 窗照搬、门洞补成实墙（厚度取相邻外墙）、门不带；

## S20 · 多选 + 采购清单导出

**G12 多选**（gap 审计）：homeowner 重新布置一个角落时，动的是「一组」——沙发 + 茶几 + 边几 + 地毯一起挪、一起转。
一件一件挪会把相对位置挪乱。

- 选择集：`selected`（主选，检视面板跟它）+ `selGroup`（Set，含主选）。**不变式：组里必须含主选**——
  任何一处直接改 `selected`（20 处）都会让组自动塌缩成单选（`selUids()` 校验），不会留下「看不见的多选」。
- 2D：Shift+点 = 加 / 减一件（不起拖）；Shift+在空白处拖 = 框选（与现有组取并集；只收当前层、框住中心的件）；
  不按 Shift 点组里的一件 = 拖整组（松手没动 = 塌缩成这一件）；点空白 = 全不选（照旧平移视图）。
- 3D 俯瞰：Shift+点 = 加 / 减；拖组里的一件 = 整组移动（贴墙只按被拖的那件算，其余同位移跟着走）。
- 快捷键作用于整组、**每个动作一步撤销**：Delete（全删）、R / Shift+R（绕组中心转 ±15°：位置绕中心转 + 各自 rot 加同一角度）、
  `[` `]`（细转）、D（整组复制、偏移 1.5ft，新件成为选择集）、方向键（整组平移）、Esc（全不选）。
  顺手修旧坑：**单选时 D 与方向键也不进撤销环**（`pushUndo` 漏写；按 Ctrl+Z 撤掉的是上一个动作）。
- 2D 画法：组里每件画虚线选中框；组的外包框（点线）；旋转手柄只在单选时有（组转靠 R / 面板按钮）。
- 检视面板：组 > 1 件时标题「已选 N 件」+ 合计价 + 「整组 +90° / 复制 / 删除 / 取消多选」；单件字段收起。
- 采购清单的行：组里的件都高亮；Shift+点行 = 加 / 减。

**G13 采购清单导出**：清单头部两个按钮「复制清单」（纯文本，贴进聊天 / 备忘录）与「导出 CSV」（Excel / Numbers）。

- 聚合：同一层 × 同一目录条目 = 一行（数量）；自定义件按「名称 + 尺寸」聚；目录里没有的件单独成行（不计价、如实说）；
  公寓自带灯具不进行、只在合计后注明件数（与界面合计同一口径）。
- 列：楼层、分类、名称、数量、单价、小计、尺寸（cm）、链接、备注（≈ 汇率折算 / * 另一配置 / 加拿大无售 / 通用尺寸件不计价 / 无价）。
- 币种 = 当前币种；合计与界面「采购 N 件 · 合计约 …」逐字一致（bench 钉住）。
- CSV：UTF-8 BOM（Excel 认中文）、每格加引号、引号转义、**`= + - @` 开头的格子前加 `'`**（CSV 公式注入：自定义件名是用户输入）。
- 纯函数在 `src/catalog/shopping.ts`（聚合 / 排序 / CSV / 文本），vitest 钉住；app.html 只负责把摆放的件解析成输入行。
- 复制：`navigator.clipboard.writeText`，失败（file:// 下权限 / 旧浏览器）退回隐藏 textarea + `execCommand('copy')`，
  再失败就弹出文本框让用户自己全选复制——不能「点了没反应」。

## S21 · 窗帘 + 墙色

**G14 窗帘 / G15 墙色**（gap 审计）：布置一间房，墙刷什么色、窗挂什么帘，和摆家具一样决定「这间房最后长什么样」。不改硬装。

- 数据：`rooms[i].wallColor`（#hex，只影响 3D）；`windows[i].curtain = {style, color, side?}`，
  款式 `drape` 落地帘（两侧收拢的两幅）· `sheer` 纱帘（整幅半透）· `drapeSheer` 两层 · `roller` 卷帘（盖住上 45% 的玻璃）。
  `side` 缺省 = 室内一侧（外墙上的窗只有一侧在地板轮廓里；内墙上的窗取有房间轮廓的那一侧）。schema 纯增量可选字段。
- 入口：**房间工具**选中一间房 →「墙色」下拉（12 个常用漆色 + 自定义取色）、「窗帘」下拉（给这间房每一扇窗配同一种帘、挂在朝这间房的一侧）；
  **窗工具条**里逐扇改（款式循环 / 颜色 / 换一侧）。每次改动一步撤销，重选同一个值不占步。清除房间轮廓时墙色一起清。
- 3D 墙色 = 沿房间轮廓刷的一层「漆」（墙皮外 1.2mm，朝房间那面可见）：轮廓每条边上，沿边走的墙 / 窗 / 门 / 开口段的端点投到边上当**精确断点**，
  断点之间再按 3cm 取样定这一段刷什么——实墙 / 柱 = 整面高，窗 = 窗台以下 + 过梁以上（落地窗不刷），门洞 = 门头以上，开口 = 不刷。
  颜色按 sRGB 解（色卡是什么颜色就刷成什么颜色）。2D 不画墙色（平面图读的是布局，墙色在 3D 里看）。
- 3D 窗帘：帘杆在窗头上 12cm（顶不到天花）、离墙皮 ~9cm；落地帘两幅各占窗宽 ~1/4、两头各伸出窗洞 15cm（伸进相邻的墙就收）；
  褶 = 沿帘宽的正弦起伏。2D：窗的室内一侧一道波浪线（落地帘两段、纱帘虚线、卷帘直线；深色帘在深色底图上提亮）。

**S21 完（2026-10-23）**：按上面落地。目检踩到一个**只在 SwiftShader 里有**的假象：贴墙薄层在大三角形上出 1px 竖向发丝线

## S22 · 开窗 / 改窗（+ 款式与外观、飘窗台）

> 来源：`docs/research/12-windows-and-input.md` §A（W1–W11）。S22a = W1–W6 + W9；S22b = W7 + W8；S22c = W10（候选）。

- **开窗 = 拆段**，不引入「墙上挂窗」的新几何：`splitWallForOpening(ent, seg, a, b, 'g'|'d')` 把一段直线实墙 / 细墙拆成

  撤销可逆，内置常量不动，`#calib` 不受影响）。两头的墙继承原墙的类型与厚度，新窗段同厚。2D 墙多边形、3D 窗台 / 过梁、房间区域、
  墙色断点、窗帘、穿墙判据全都按墙段链读，拆段之后一行不改就对。挂在这段墙上的点位按 `at` 分到左 / 右段（右段 `at` 减去偏移，
  FT4 取整 = 与缓存坐标同一个口径，改挂之后原地不动），落在洞里的一起去掉、提示里说个数（与轮㊳「换类型去掉点位」同一条规则）。

  窗中心离墙段中点不到 10 屏幕像素就吸到正中（按住 Alt 不吸）；两头各留至少一小截墙（`STUB_MIN` ≈ 5cm），放不下就收窄并说明；
  点到已有的窗 = 选中它（按住就能拖）。工具条：常用尺寸（中国 1500 / 1200 宽、卫生间高窗台、北美 36×30″ / 72×18″、落地窗）+
  宽 / 窗台 / 窗高 / 款式。选中一段实墙时多一个「在这段开窗」（墙段中点开一扇；墙段不比窗 + 两头各一小截长 = 整段换成窗）。
  「加门」点在实墙上 = 先开 80cm 门洞再放门（以前只认已有的门洞，要先画一段「门洞」类型的墙）。

  一头没有能跟着伸缩的墙（整段换成的窗、顶着拐角）= 这一头不动。提示里实时写「离左端 X · 离右端 Y」（按屏幕方向说左右 / 上下）。

## S23 · 键鼠操作统一（完，2026-10-25）

> 来源：`docs/research/12-windows-and-input.md` §B（现状全表 K1–K10、参照 The Sims 4 / Figma / 三维编辑器 / 第一人称游戏、规则 1–7）。

**一张表**：`INPUT_MAP`（app.html）= 快捷键面板的唯一来源；按 `?`（或底部提示行末尾的「? 全部快捷键」）打开，按组列出（镜头 / 视图 / 选中的东西 /
鼠标 / 修饰键 / 画线 / 命令 / 帮助）。bench 断言面板一行一条、文字与表一致。

**规则**（三个视图一个口径）：
- **WASD = 镜头**：平面图平移图纸（60 屏幕像素一下）、3D 俯瞰平移镜头（目标点一起走）、室内走路；**Shift = 快 / 跑**。**Q / E = 转镜头**
  （俯瞰绕目标 5°、室内原地转；Shift 大一步；两个视图同向：Q = 往左）。**1 / 2 / 3** = 平面图 / 俯瞰 / 室内，**F** = 回到全貌，
  **PageUp / PageDown** = 上一层 / 下一层（只有一层时说一声）。带 Ctrl / ⌘ / Alt 的一律不当镜头键。
- **方向键 = 挪选中的东西，1cm 一步、Shift 10cm**——家具、墙、门 / 窗（沿墙）、洁具、点位、整层、底图全一样（以前家具 7.6cm / Shift 2.5cm、
  墙 Shift 5cm、底图 10cm / Shift 2.5cm：三套步长、Shift 方向还相反）。
- **修饰键**：Shift = 约束 / 大一步（拖家具锁横 / 竖 · 画墙 / 拖墙端点锁 0° / 45° / 90° · 旋转手柄 15° 一格 · `[ ]` 15° · 方向键 10cm）；
  Alt = 不吸附 / 自由（贴墙、端点 / 墙线、中点吸附全关 · 旋转手柄自由角度 · `[ ]` 0.1°）；Ctrl / ⌘ = 命令（撤销 / 重做 / **复制 = Ctrl/⌘+D**）。
- **旋转**：R / Shift+R ±15°、`[ ]` ±1°，家具**与洁具**都吃（以前洁具只能在框里输角度）；3D 里**右键拖家具 = 转**（以前 Shift+拖），
  Shift+拖 = 锁横竖挪（与平面图同一口径）。
- **鼠标**：右键 / 中键拖 = 平移，平面图任何模式都一样、不再弹浏览器菜单（以前摆家具时右键弹菜单、编辑墙体时右键平移）。
- **模式之间不串键（K1）**：室内视角里改家具的快捷键一律不作用——以前按 D（向右走）会同时复制选中的家具（按住不放复制一串），
  方向键边走边挪它，R / Delete 作用在看不见的那件上。**Shift 跑（K2）**以前从来没生效（走动的按键表里没有 Shift）。

**对老用户手感的改动**：复制 D → Ctrl/⌘+D；家具方向键 7.6cm → 1cm、Shift「更细」→「10cm」；墙的 Shift 5cm → 10cm；底图 10 / 2.5cm → 1 / 10cm；
画墙「Shift = 不吸附」→ Alt（Shift 改为锁 0 / 45 / 90°）；3D 里 Shift+拖不再转（改右键拖）；旋转手柄 Shift「自由」→「15° 一格」（自由改 Alt）；
`[ ]` 0.5° → 1°。底部提示与快捷键面板写的就是新口径。

**验证**：bench 每条规则在每个模式下各一条断言，含反例（开着面板按 D 不平移 · Ctrl+R 不转 · 编辑墙体按 R 转洁具不转家具 · 右键拖在家具上只平移 ·
室内按 D / 方向键 / R / Delete 家具原样）；老断言里按旧手感写的逐条改写（26.6 / 26.7 复制改 Ctrl+D、方向键步长；门的 Shift 步长 5 → 10cm；
㊱ 那条隔墙挪 30cm 的按键次数 6 → 3；t_3d「Shift+拖 = 转」→「右键拖 = 转」+「Shift+拖 = 锁轴」）。E2E 新流程 `input-scheme`（真键盘 / 真鼠标）。

**S23 独立审查（只给代码、不给结论）**钓出的，全部先红后绿（t_planbuild 第 43 节 + t_3d「S23 独立审查」块）：

- 已经在室内时再按 3 = 瞬移回进入点（俯瞰再按 2 = 机位复位）→ 已经是这个视图就不动。
- 快捷键面板只挡住了主监听器的后半段：开着面板按 W 照样走、Ctrl+Z 照样撤销、Esc 先被工具行吃掉 → 面板在**窗口捕获阶段**接管键盘。
- Shift 一键两义：平面图里先按 Shift 再拖 = 加减选、拖不动；3D 里 Shift+拖一件没选中的不改选择（接着按 Delete 删的是旧的那件）→
  按下时先不决定：松手时没拖开 = 加减选、拖开了 = 锁轴挪（没选中的先选中它）。
- 「Alt = 不吸附」撞上「Alt+点柱子顶点 = 删」→ 同样按「拖没拖开」区分；顶点拖动的 Shift 锁角以前一个顶点为锚（以前锚到了正在画的线上）。

  AZERTY、西里尔布局、按着 Shift 打数字都对）；正俯视时 WASD 的方向用屏幕的「上」。

  加自定义目录）在别的方案里改过 → 这套的旧记录作废并说出来（旧快照一恢复会把那些改动一起退掉）。量尺寸标注不算共用内容（量一下就作废别的方案的撤销，代价太大）。

  删户型的确认说「它的 N 套方案和每套的家具也在里面」；`#calib` / 只显底图不显示方案按钮（calib md5 不变）。
