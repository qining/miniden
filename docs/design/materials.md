## 0. 怎么读

### 0.1 三条约定（沿用 facelift §0.1）

1. **id 和处理器尽量不动**。S25 的影子控件（`#rmFloor` `#rmWall` `#rmAngle` `#lvFloor` `#dKind` `#dWood` `#wWinFrame` `#wWinFrost` `#wWinCurtain` / `#wWinCurtainSel` 等）继续留在 DOM 里当**状态源和处理器入口**；新视图（材质行、选择器、小图示）只做两件事：赋值 / 派发 `change` / `click()`，以及读取值来显示选中态。
2. **新字段全部可选**。不设新字段的旧文档、内置户型，2D 和 3D 必须和现在一模一样（§8 的约束）。所以每个新选项列表的**第一项都是「缺省」**，它的外观等于现在写死的样子（§7.4 列出了这些值）。
3. **`#calib` 不受影响**：新的 2D 元素（墙面色带、洁具新图例、选中墙面的描边）全部走 `!CALIB` 分支，并且只在「装修」分区里画（§5.5、§11）。

## 1. 设计原则

1. **对象优先**：先选中一个东西（2D 里点、左栏点房间、检视面板里点「这个房间的墙」），检视面板只列它的几行。检视面板**不再整片铺色块**（解决 research §3.1-a/b/c）。
2. **选项多少决定控件**（本规格的核心规则）：

   | 选项数 | 控件 | 例子 |
   |---|---|---|
   | 2–4 个，文字短 | 分段控件 `.seg.sm` | 铺法、方向、墙砖高度、宽度档、落地 / 悬挂、玻璃 |
   | 2–8 个，形状不同 | **小图示单选** `.icons`（图示 + 两到四个字） | 洗手台形式、马桶、淋浴、浴缸、门板、窗格、帘型、柜门板 |
   | ≤ 8 个，颜色 / 材质 | **一排色块** `.swRow`，直接放在检视面板里 | 门颜色（7 + 自定义）、窗框 5、台面（缺省 + 6）、百叶颜色 3 |
   | > 8 个 | **材质行** `.mrow` → 左栏**选择器** | 地面 45、墙面（42 色 + 24 墙纸）、墙砖 8 + 无、柜色、窗帘颜色 16 / 42 |

3. **「是什么」放在选择器里，「怎么铺」放在检视面板里**：材质本身（哪种木地板、哪种砖）在选择器里挑；铺法、方向、墙砖高度这些是「这一次怎么用」，跟着材质行放在检视面板里，关掉选择器以后还看得见、改得了（§13 分歧 3）。
4. **悬停 = 预览，点击 = 确定，Esc = 撤回**：在选择器里悬停时，2D 和 3D 都立刻换上，移开就恢复；点一下才写进文档（一步撤销）。
5. **2D 只做提示**：墙面色带和房间行里的三个小色块告诉你「这里设过什么」，不去模拟图案（research §0-5）。

## 2. 材质行（检视面板）

### 2.1 材质行的结构 `.mrow`

```
┌──────────────────────────────────────────────┐
│ ┌────┐ 地面                      [单独设置] ▸ │  ← 行名（11px 灰）· 状态芯片 · ▸
│ │缩略│ 白色哑光砖                              │  ← 名字（13px，一行，超长省略号）
│ └────┘ 60 × 60 · 直缝                          │  ← 规格（11px 灰）
└──────────────────────────────────────────────┘
  高 46，内边距 6 / 8，缩略图 36 × 36，整行都可点（<button>）
```

| 状态 | 外观 |
|---|---|
| 常态 | `--panel2` 底，1px `--line` 边 |
| 悬停 | 边变成 `--muted` |
| **打开中**（选择器正在改它） | `--sel-bg` 底 + `--accent-line` 边 + 左侧 3px 琥珀内阴影；▸ 换成 ◂ |
| 预览中 | 名字后面加「（预览中）」，缩略图换成预览的材质 |
| 「无」 | 缩略图是灰色斜纹（`.mt.none`），名字写「无」 |

状态芯片 `.st`（只在需要分清「继承」还是「自己设的」时出现）：

| 芯片 | 含义 | 样式 |
|---|---|---|
| 跟全屋 | 房间没单独设地面 | 灰边 |
| 这个房间 / 单独设置 | 房间单独设了地面；墙面单独设置 | `--accent-line` 边 + 琥珀字（`.st.own`） |
| 跟房间 | 单面墙沿用房间的设置 | 灰边 |
| 整个房间 | 房间级的墙砖 / 墙面 | 琥珀 |

点一行 = 在左栏打开选择器，选择器的目标就是这一行（§3）。选择器开着时再点另一行 = 直接换目标，不关闭。

### 3.4 交互

| 动作 | 结果 |
|---|---|
| 点材质行 | 打开选择器，目标 = 这一行；材质行变成「打开中」 |
| 鼠标进入一格，停 **120ms** | **预览**：这个对象在 2D 和 3D 里临时换上（不写文档、不进撤销、不保存）；这一格加蓝色预览环（`--preview-line`）；`#mpReadout` 显示名字 + 规格 +「预览中」；材质行显示「（预览中）」 |
| 在格子之间移动 | 直接换预览，不先恢复（避免闪） |
| 鼠标离开网格区 **80ms** 以后 | 恢复到当前值 |
| 键盘：方向键在网格里移动焦点 | 焦点 = 预览（和悬停一样） |
| **点一格 / 回车** | **确定**：写进文档，一步撤销，存档；这一格变成 ✓；**选择器不关**，可以接着比较（读数标签从「预览中」变成「已用上」，1.2s 后消失） |

| 选择器开着时，在画布上点别的对象 | 新对象有同一个槽位（比如另一个房间的地面）→ 换目标，选择器不关；没有 → 关闭 |

| ⌘Z | 照常撤销；选择器的 ✓ 跟着刷新 |

### 3.5 搜索、色调、最近用过、这套房子已用、密度

- **搜索** `#mpSearch`：输入时自动切到「全部」页签，按名字、规格、分类、色系和同义词匹配，不区分全角半角。同义词：
  - 「白」→ 所有名字里带白的，以及白色系；「灰」「木」「橡」「砖」同理
  - 「大理石」→ 石材类；「60」→ 60×60、60×120；「地铁」→ 地铁砖；「人字」→ 人字拼、人字纹
  - 搜不到：「没找到“{词}”。试试颜色（白、灰）或规格（60×60）。」
- **色调** `#mpTone`：
  - 浅 / 中 / 深按 CIELAB 明度 L\* 分：浅 ≥ 75，中 45–75，深 < 45。
  - 暖 / 冷按色相分：彩度 C\* > 6 时，色相 0–90° 或 300–360° 算暖，90–300° 算冷；C\* ≤ 6 的中性色两边都不算。
  - 同一组里多选是「或」，两组之间是「且」。材质按代表色（`tint`）算。
  - 筛选有值时，页签上的数字跟着变。
- **最近用过**：按槽位类型分四类记录（地面 / 墙面 / 墙砖 / 颜色——门、柜体、布料共用「颜色」这一类），每类最多 8 个，最新的在左；自定义颜色也进来。存 `localStorage` 键 `md_matRecent_v1`。没有记录时这一行不显示。
- **这套房子已用**：统计当前户型（所有楼层）里这一类用到的材质，按次数降序，最多 8 个，右上角 `×N`。不跟方案走（装修外观本来就不跟方案走）。
- 两排小方块的行为和网格格子一样（悬停预览、点击确定）。
- **密度** `#mpDensity`：▦ 大图（3 列，图 4:3 + 名字 + 规格）/ ▪▪ 小图（5 列，方图，名字只在读数里）。按槽位类型记住，键 `md_matDensity_v1`。色板槽的「小图」就是色板矩阵（§4.1），「大图」是 3 列带色名。

## 5. 墙面

### 5.1 两层：整个房间 + 单面墙覆盖

| 层 | 数据（建议，工程定） | 界面 |
|---|---|---|
| 整个房间 | `room.wallColor`（现有）· **新** `room.wallMat?`（墙纸）· **新** `room.tile?`（墙砖 + 高度 + 铺法） | 房间检视的「墙面」「墙砖」两行 |
| 单面墙 | **新** `room.faces?[]`：按「房间 + 这条墙线」存（端点 + 法线，共线判定；research §3.2，开窗把墙拆成三段时覆盖不丢） | 单面墙检视 |

- 墙面槽的取值是**涂料或墙纸二选一**；墙砖是叠在上面的一层（从地面铺到「高度」为止），砖以上露出墙面。
- 单面墙的「墙面」「墙砖」各自独立地「跟房间」或「单独设置」。
- 清除单独设置 = 两项都回到跟房间（`#faceClear`）；单项清除 = 在选择器里点第一格「跟房间」。

### 5.2 怎么选中一面墙

- 装修的「选择」工具（`data-t="deco"`），点击时的判定顺序：
  1. 门、窗、洁具、台面（和现在一样）
  2. **墙面**：点在某个房间里，并且离这个房间的某面墙的内皮 ≤ **max(30 cm, 10 屏幕像素)** → 选中这面墙的房间一侧
  3. 房间（和现在一样）
- **悬停预高亮**：鼠标进入墙面判定区，这面墙的房间一侧就出现 2px 琥珀虚线框（色带外框），光标变成指针；提示行写「点一下 = 只改这面墙（上墙 · 366 cm）」。
- **命名**：按平面图方位写「上墙 / 右墙 / 下墙 / 左墙」（平面图不一定上北下南，所以不用东南西北）。斜墙按法线方向归到最近的那一侧；同一侧有几段时，从左到右或从上到下编号：「上墙 1」「上墙 2」。后面都跟长度：「上墙 · 366 cm」。
- **3D 里**（3D 点选是 S27 的事）：通过房间检视里的「这个房间的墙 ▸」列表来选，每行可点。
- 选中墙面时，2D 里这面墙的色带外框是 2px 实线琥珀；如果选择器正在预览，换成蓝色（`--preview-line`），旁边写「预览：墨绿」（原型 `#wall`）。
- 选中墙面后按 Esc → 回到选中这个房间（一层一层退：墙面 → 房间 → 全不选），和 S25 的 Esc 规则一致。

### 5.3 「应用到…」（`#mpScope`）

| 从哪打开 | 显示 | 缺省 |
|---|---|---|
| 单面墙的「墙面」/「墙砖」 | [这面墙 \| 整个房间] | 这面墙 |
| 房间的「墙面」/「墙砖」 | [这面墙（禁用）\| 整个房间]，后面灰字「先在平面图上点一面墙才能只改那面」 | 整个房间 |
| 其他槽位 | 不显示 | — |

- 在单面墙上切到「整个房间」= 选择器的目标换成房间。这时点一格，会写进房间的设置，**并且清掉这面墙的单独设置**；否则用户会看到「我点了，选中的这面墙却没变」。其他墙的单独设置不动，读数里说一句「另有 N 面墙单独设置，不受影响」。
- 切回「这面墙」= 目标换回这面墙。

## 8. 缩略图（程序化生成，不用外部图片）

### 8.1 画法

- 每一类材质只有**一个画法函数** `drawMat(ctx, mat, pxPerCm)`。3D 贴图（≤ 512px）和缩略图都调用它，只是传入的比例不同，所以两边看起来一样。原型里的 `thumb()` 就是这个思路的演示（木板错缝、人字、方砖、地铁砖、六角、棋盘、大理石纹、水磨石、洞石、花砖、噪声、8 种墙纸、木纹、不锈钢）。
- **统一真实比例**：地面、墙砖、墙纸的缩略图都代表 **120 × 90 cm** 的一块，所以宽板和窄板、7.5 × 15 和 10 × 20 放在一起比，大小是对的。台面代表 60 × 45 cm，木纹色块代表 40 × 40 cm。
- 随机数按材质 id 固定种子，同一个材质每次画出来都一样（黄金截图才稳定）。
- 纯色（色板、门色、柜色、布料）**不用 canvas**，直接用 CSS 背景色。

### 8.2 尺寸

| 用在哪 | 显示（CSS px） | 画布（2 倍屏） |
|---|---|---|
| 选择器 · 大图 | 89–101 宽 × 4:3 | 192 × 144 |
| 选择器 · 小图 | 51–58 方 | 用 192 × 144 那张，中心裁成方的（不另画） |
| 墙纸行 | 89–101 宽 × 2:1 | 192 × 96 |
| 最近用过 / 已用 | 36 × 36 | 72 × 72（从 192 × 144 裁） |
| 材质行 | 36 × 36 | 同上 |
| 房间行三个小色块 | 14 × 14 | 28 × 28 |
| 台面一排 | 30–34 方 | 68 × 68 |
| 门 / 柜的木色格 | 24 方 | 48 × 48 |

### 8.3 生成与缓存

- **懒生成**：选择器打开时，只画进入可视区的格子（`IntersectionObserver`）；每帧最多 4 张，用 `requestAnimationFrame` 分批，没画好的格子先用材质的 `tint` 纯色占位。
- **缓存**：`Map`，键是 `${id}@${w}x${h}`，值是 JPEG dataURL（质量 0.85，每张约 5–8 KB）。45 种地面 + 8 种墙砖 + 24 种墙纸 + 7 种台面 ≈ 84 张 × 约 7 KB ≈ 0.6 MB，切换户型也不清。
- **小图示**（洁具形式、门板、窗格、帘型、柜门）：内联 SVG（`viewBox="0 0 30 30"`，`stroke-width:1.4`，`fill:none`），选中时描边变成 `--accent`。洁具的那几种和 2D 图例共用一组路径定义（2D 按真实尺寸缩放，图示归一化）。

## 13. 与 research/15 的分歧（以及理由）

| # | 本规格的做法 | research 的说法 | 理由 |
|---|---|---|---|
| 1 | 选择器**沿用左栏当前宽度**（1280 = 307，1440 = 346），不改成固定 340 | §3.2「宽约 340px」 | 临时加宽会让画布变窄、平面图重新取景，**悬停预览的位置会跳**，正好破坏这个功能最核心的体验；307 宽也能放 3 列（每格 89px，原型实测）|
| 2 | **≤ 8 个选项直接放在检视面板里**（门色 8、门板 5、窗格 4、帘型 8、台面 7、洁具形式），不全走「材质行 → 选择器」 | §3.2：检视只列材质行，点了开选择器 | 少的选项开一个选择器反而多一步；一排 8 格加一行字，比一个材质行（46px）也高不了多少。多于 8 个的（地面、墙面、墙砖、柜色、布料）才走选择器 |
| 3 | 铺法、方向、墙砖高度放在**检视面板的子行**里，不放在选择器里 | §3.2 的线框没写；§3.3 的路径「选砖 → 高度选半高」暗示在同一处 | 这些是「这一次怎么用」，不是材质本身；关掉选择器以后还得看得见、改得了。新设墙砖时按房间类型给高度缺省值（卫生间 = 淋浴区、厨房 = 防溅区），所以 research 说的「5 下」不变 |
| 4 | 点一格 = 确定，但**选择器不关**；另加「↺ 还原」 | §3.2「点 = 确定，Esc = 撤回预览，回到上一层」 | 不关是为了能接着比较（悬停预览一移开就恢复，要比两种就得点下去看）；「还原」给「试了几种都不满意」一个一步回去的出口 |
| 5 | 在单面墙上选「整个房间」并点一格，会**同时清掉这面墙的单独设置** | 没写 | 否则用户选中这面墙、改了「整个房间」，眼前这面墙却不变，像是没生效 |

| 7 | 墙的命名用**上 / 右 / 下 / 左**（平面图方位） | 线框里写「床头墙」 | 平面图不一定上北下南；「床头墙」需要猜家具的用途，不可靠。自定义墙名是 P2 |
| 8 | 房间的窗帘颜色是**「窗帘」行里的一个色块**，不单独占一行材质行 | §3.2 线框是「窗帘 不挂（2 扇）▸」一整行 | 省 46px，保证选中房间时检视面板在 1440 下不用滚 |
| 9 | 「地板」全面改叫**「地面」** | research 混用 | 选项里有瓷砖、地毯、水泥；会改到 S25 的几条文案断言，在实现包里一起改写 |
| 10 | 白色系按明度重排（纯白 > 冷白 > 奶白 > 暖白 > 象牙白） | §2.1 的顺序 | 每行「从浅到深」要说到做到；色值和名字都没变 |

| 面（地面、墙内侧、天花） | 一块贴合的「面片」+ 一圈「边线」。面片复用地面多边形、墙内皮的矩形、天花多边形 |
| 物件（洁具、门、窗、台面 / 柜） | 物件网格的 `EdgesGeometry`（`thresholdAngle 25°`）边线 + 地上一块占地矩形面片（`y = 0.5 cm`） |

| 状态 | 颜色 | 面片不透明度 | 边线不透明度 | 什么时候 |
|---|---|---|---|---|
| **悬停** | `#d9a05b`（`--accent`） | **0.34**（浅色表面 **0.20**） | **0.85** | 鼠标停在一个可选对象上（命中后马上显示，不做延迟） |
| **选中** | `#d9a05b` | **0.26**（浅色表面 **0.14**） | **1.00** | 选中以后一直显示，直到取消选中 / 换选 / 离开装修 |
| **预览中**（选择器正在悬停预览，目标就是这个选中对象） | `#7fb8ff`（`--preview-line`） | 0.26（浅色表面 0.14） | 1.00 | 和 2D 的预览环同一个蓝色；数值跟「选中」一样 |
| 选中 + 悬停在同一个对象上 | 按「选中」画，不叠加 | — | — | 避免两层叠出的颜色发黄发脏 |

- **粗细**：WebGL 线宽固定是 1 物理像素（这个工程只 vendored 了 `three.min.js` 和 `OrbitControls`，没有 `Line2`），所以不靠加粗线来区分状态，靠**面片不透明度**和**边线不透明度**来区分。高 DPI 屏幕上 1px 的线偏细，边线**画两遍**：第二遍沿面法线往外偏移 2.4 mm，看起来像 2px（S27a 实现采用，定为规定）。叠加层材质一律 `toneMapped:false`，不然琥珀色会被 ACES 色调映射压暗。

> **2026-11-04 修订（S27a 实测后）**：原定的面片 0.10 / 0.16 在深色地板上看不出来，工程实测后改成选中 0.26 / 悬停 0.34、边线 1.0 / 0.85，边线画两遍。UI 组确认采纳，并补一条：**浅色表面（白墙、浅色天花、浅色地面）上面片减到 0.14 / 0.20**。原因是截图 `work/ux/shots/s27/a-3d-pick.png` 里，白墙在悬停时叠了 0.34 的琥珀，看起来像刷成了米黄色，会被误读成「材质已经变了」。浅色表面在这里靠边线来识别就够了。判定方法：取这块表面当前材质的代表色（`tint` 或墙色），相对亮度大于 0.6 就算浅色。悬停仍然比选中强；悬停在已选中的对象上时按选中画（规则不变）。

- **深度**：`depthTest:true`、`depthWrite:false`、`polygonOffset`（factor −2，units −2）、`renderOrder 10`。墙面片沿墙法线往房间里偏移 **3 mm**，地面片和天花片分别抬高 / 压低 3 mm，以免和原表面 z-fighting。被别的东西挡住的部分**不画**（不做透视描边，否则俯瞰时会穿墙看到对面房间的高亮）。
- **面片的形状**：墙面片按墙内皮的整个矩形画，不抠门窗洞（简单、稳定）；地面片用房间范围的多边形；天花片和地面片同形，放在层高处。
- **不进出图**：「拍一张效果图」（光追）和「导出平面图图片」时隐藏全部叠加层；光追冻结期间也不画。

### a.2 命中规则（射线打到的第一个面，按 research/16 §3.1）

| 打到 | 选中 | 标签第 1 行 |
|---|---|---|
| 地面 | 这个房间 | `{房间} · 地面` |
| 墙的**室内一侧** | 这面墙（和 2D 点墙边选中的是同一个对象） | `{房间} · {方位}墙` |
| 墙的室外一侧 / 墙顶截面（俯瞰视角里的墙头） | 不选 | 不出标签，光标保持缺省 |
| 天花（只有室内视角能点到） | 这个房间的天花（S27b 起才有天花行；S27a 先选中房间，检视面板显示房间） | `{房间} · 天花` |

| 门（门扇、门套） | 门 | `门 · {房间 A} ↔ {房间 B}` |
| 窗（玻璃、窗框、窗帘、百叶） | 窗 | `窗 · {房间}` |

| 家具 | **不响应** | 标签用灰字写「家具在「摆家具」里改」；不描边；光标保持缺省 |
| 空白 / 天空 / 窗外环境 | 什么都不做（单击空白**不取消**选中，免得转视角时误取消；取消用 Esc） | 不出标签 |

- **单击和拖动的区分**：按下到松开的移动距离 ≤ **5 px**，并且时长 < 500 ms，才算单击。超过就是转视角或平移，不选、不改选中。
- **室内视角里的双击**：双击地面仍然是「走过去」。为了不和单击打架：第一下单击**立即**选中（不等 300 ms 判断是不是双击，反应要快）；第二下在 300 ms 内落在地面上 → 走过去，选中保持在第一下选的那个房间（两下点的是同一个东西，选中没变，不算误触）。
- 只在「装修」分区生效。「摆家具」在 3D 里照旧拖家具；「改户型」在 3D 里照旧只读。

### a.4 选中以后

- **不移动相机**（research §3.1）。
- 选中态的叠加层一直显示；转视角、走动时跟着对象走（它就是场景里的几何）。
- 检视面板切到这个对象；左栏选择器如果开着并且目标是同一类槽位，就换目标（§3.4 的规则不变）。
- 2D 和 3D 共用同一个选中对象：切回 2D 时，2D 里也是选中它（墙面描边、房间描边照旧）。
- 选中的对象在画面外（比如室内视角里它在身后）：什么都不提示，检视面板照常显示。
- Esc 一层一层退（墙面 → 房间 → 全不选），和 2D 一致；退到房间时，叠加层从墙面片换成地面片。
- **提示行 `#hint` 的第一段**在选中后显示状态，和 2D 装修一致：例如「**卧室 1 · 上墙** · 墨绿涂料 ｜ 换材质 → 右边检视面板」。

### a.6 calib 与其他约束

- 3D 点选只发生在 3D 视图里，calib 是 2D 视图：两者不相交。`#pick3dTip` 加 `body.calib #pick3dTip{display:none !important}` 兜底。
- M04（斜墙台阶收成长边）是几何修复，没有新的界面元素。唯一的界面影响是「这个房间的墙（N）」的 N 变小、墙名变得有意义（「左墙 3」而不是「上墙 72」），这一项的文案规则不变（§5.2）。

### a.7 S27a 的设计验收点

1. 在 3D 俯瞰里点地面 / 墙内侧 / 马桶 / 门 / 窗，检视面板分别切到房间 / 单面墙 / 马桶 / 门 / 窗；在室内视角里点天花能选中。
2. 拖动转视角（> 5 px）不会改变选中。
3. 悬停时：面片（0.34，浅色表面 0.20）+ 边线（0.85）是琥珀色；白墙悬停时不会被看成「刷成了米黄色」，标签两行，出现在鼠标右下方，靠近边缘会翻转；按下鼠标标签立刻消失。
4. 选中后转一圈视角，高亮还在，并且不会穿墙显示到对面。
5. 选择器悬停预览时，选中对象的高亮变成蓝色；移开后变回琥珀。
6. 点家具：不选中，提示行出现「家具在「摆家具」里改」。
7. 「拍一张效果图」里没有高亮；`#calib` md5 不变。

### b.3 天花

- 行 `#mrCeil` → 选择器新槽位「天花」（`#ceil`）。
- 页签 [常用 2 \| 全部色板 42]。常用页签里有两格：「白（缺省）」= 现在的白；「跟墙」显示当前墙色，选它以后改墙色时天花也跟着变（整间同色，color drenching）。
- 规格那一行写「只在室内视角看得到」（俯瞰掀了顶）。在 2D / 俯瞰里打开天花选择器时，读数下面加一行灰字：「切到室内视角看效果」，「室内视角」是链接。
- 室内视角里点天花 = 选中房间，并且**直接打开天花选择器**。点地面不会自动开选择器；点天花自动开，是因为房间里能「点天花」进行的操作只有这一项。

### b.4 地面铺法（S09 改口径）

- `#mrFloor` 的展开区：
  ```
  铺法 [直铺|错缝 1/2|错缝 1/3]    ← #rmLay
  方向 [0°|45°|90°|135°]          ← #rmAngleSeg
  ```
  - **铺法**只对板材（木地板、SPC、木纹砖）和矩形砖（长边 ≥ 2 倍短边）显示。
  - **方向**对地毯、水泥、水磨石、大理石（无方向的材质）**不显示**（QA S09）。
- 选择器里不再有单独的「错缝」格子：S26 里以「xx 错缝」命名的地面条目，旧档读出来映射成「材质 + 铺法」，显示时名字里不再带「错缝」。木地板页签的数字跟着变少。
- 地面选择器的大图网格**统一按直铺**画缩略图，让每种材质看起来都一样大小，选完再在展开区里调铺法。

### b.5 墙裙（护墙板）：墙砖选择器的第二个页签（`#wains`）

- `#mrTile` 打开的选择器改名「墙的下半截」，页签 [墙砖 8 \| 护墙板 3]，网格最后有一格「不装」。

- 墙砖和护墙板**二选一**：选护墙板会替换掉墙砖，选择器里有一行说明。行名跟着变：有砖叫「墙砖」，有护墙板叫「墙裙」，都没有叫「墙的下半截」。
- 护墙板的展开区：
  - `#wainH` [90 \| 120] cm（英尺：[36″ \| 48″]）
  - `#wainColor` 一排：纯白 · 暖白 · 浅灰 · 灰绿 · 海军蓝 · 色板…
  - 缺省「暖白 · 90」
- 墙砖的展开区（S26 的高度、铺法）再加一行**填缝**，属于 S27d，见 d.4。

### b.6 S13：选择器总是贴着左边缘

不论左栏是不是收起，选择器打开时一律 `left:0`，宽度用左栏的存档宽度（S26 §3.1 不变）。修掉「收起状态下打开，往右偏 24px（竖条 `#catTab` 的宽度）」的错位：打开时先隐藏 `#catTab`，关掉时恢复。

### b.7 S27b 设计验收点

1. 1440×900，选中卫生间（地面、墙面、墙砖都有值，踢脚线展开）：检视面板不滚动。
2. 同一时间只展开一行；关掉选择器以后，规格那一行写着铺法 / 高度。

4. 选「跟墙」做天花后再改墙色，天花跟着变。
5. 地毯、水泥没有「方向」；木地板有「铺法」；选择器里找不到「错缝」格子。
6. 选护墙板替换掉墙砖；踢脚线自动变成「跟墙裙」。
7. 左栏收起时打开选择器，选择器贴着左边缘。

- 吸管吸墙砖时连填缝一起吸。

### d.5 装修用量（清单页签，`#usage`）

S26 的「地面用量（不含损耗）」这一节扩展为：

```

按面积估算 · 不含损耗 · 不计价                          ← 11px 灰字，紧跟在标题下面
▦ 地面 · 浅色白橡                     卧室 1        22.3 m²
■ 涂料 · 雾蓝                         卧室 1（3 面）  约 9 L

                                                42.1 m² · 5.3 m²/卷
▦ 墙砖 · 白色地铁砖 7.5×15             卫生间 · 1.2 m  10.2 m²（灰缝）

▬ 踢脚线 · 白 8 cm                    4 个房间       46.8 m
```

| 项 | 规定 |
|---|---|
| 排序 | 地面 → 涂料 → 墙纸 → 墙砖 → 护墙板 → 踢脚线；同类里按用量从大到小 |
| 每行 | 14px 缩略 · 「类别 · 材质名」· 第二行灰字写用在哪（一个房间就写房间名，多个写「N 个房间」，单面墙写「卧室 1 上墙」）· 右边是数量，第二行灰字写计算依据 |
| 单位 | 涂料 L（面积 ÷ 10 m²/L × 2 遍，向上取整到 1 L，写「约」）· 墙纸 卷（面积 ÷ 5.3 m²，向上取整）· 墙砖、护墙板、地面 m²（一位小数）· 踢脚线 m（一位小数，扣掉门洞）。英尺单位时：面积 ft²、长度 ft、涂料 gal（÷ 350 ft²/gal × 2 遍） |
| 行为 | 点一行 = 在图上选中用到它的第一个房间 / 墙（和家具的 ◎ 定位同一个手势）；没有 ✕ |
| 没有任何装修设置 | 这一节整个不显示 |
| 导出 | CSV 加一组：类别 / 材质 / 位置 / 数量 / 单位 / 依据；「复制清单」把这一节放在家具后面，标题「装修用量（估算，不含损耗、不计价）」 |
| 合计 | **不进合计**（不计价），芯片和底部合计不变 |

### d.6 S27d 设计验收点

1. 新手两下看到整套效果：点「整屋配色」→ 悬停一张卡。
2. 套用 = 撤销栈 +1，⌘Z 一下全部回去；toast 的文案按 d.2 的条件变化。
3. 「只填没设过的」不会改动已经设过的房间；影响数为 0 时「套用」禁用。
4. 吸管：吸墙 → 粘到另一面墙，可以连续粘；悬停地面时光标变成禁止、标签说「只能粘到同类」；Esc 分两步。
5. 用量：墙纸的卷数、涂料的升数按 d.5 的公式取整；CSV 里有这一组；合计金额不变。
6. 原型里的方案小样没有用任何图片。

### e.2 冲突与 2D

| 情况 | 做法 |
|---|---|
| 吊柜的高度区间（台面高 + 离台面 → + 高度）碰到窗洞、门洞 | 那一段**不装**；展开区里用 `.note.warn` 列出被跳过的段（「上墙那一段挡住了窗（120 cm）」）；2D 里那一段不画 |
| 吊柜顶超过层高 | 自动压到层高下 2 cm；`.note.info`「层高 259：吊柜压到 87 cm 高」 |
| 和冰箱、高柜、油烟机（模块）重叠 | 那一格不装，同样列在提示里 |
| 和家具（高柜、壁挂电视）的高度区间重叠 | 走 S19a 的高度区间碰撞，家具标红（和现在一样） |
| 2D | 吊柜画成**虚线外框**（4 / 3，`#e8e4dc`，1.2 屏幕像素），贴着台面靠墙的一侧，深 33，不填色（「头顶上的东西用虚线」是平面图惯例）；装修和摆家具里都画，calib 不画 |
| 3D 点选 | 打到吊柜 = 选中这组台面 / 橱柜，标签写「吊柜」，检视面板自动展开「吊柜」那一行 |

### e.3 S27e 设计验收点

1. 装吊柜以后，2D 里能看到虚线框，窗前那一段是空的，并且提示里写了原因。
2. 吊柜颜色选一个跟地柜不同的颜色，芯片出现「双色」；选回「同」，芯片消失。
3. 吊柜在高度上碰到壁挂电视，电视标红。
4. 旧档、内置户型没有吊柜，3D 逐像素不变。

## S27 · 与 research/16 的分歧

| # | 本规格 | research/16 | 理由 |
|---|---|---|---|
| 1 | 材质行改成**紧凑行**（40px，行名在左），并且只允许**一行展开** | §3.2：把「铺贴方向」「这个房间的墙」收进各自材质行的展开区 | 只收这两项不够：S26 落地的行高是 64px，加三行之后 1440 下还要多出约 200px。紧凑行 + 手风琴 + 名称并进标题，实测一屏放得下 |
| 2 | 踢脚线的颜色是**展开区里的一排 7 格**，不开选择器 | §3.2 线框写成「白 · 8cm ▸」 | 选项 ≤ 8 个，按 S26 §1 的规则直接放在面板里；只有「自定义…」才开色板 |
| 3 | 天花的「跟墙」是**跟随**（改墙色时天花跟着变），不是复制一次 | §2.1「白 / 跟墙 / 色板」 | 整间同色这种做法，用户改墙色时期望天花一起变 |
| 4 | 室内视角里点天花 = 选中房间**并且直接打开天花选择器** | §3.1：天花是一个可以选中的对象 | 房间里「点天花」能做的事只有改天花颜色；少一次点击 |
| 5 | 吸管除了 Alt 以外，**模式条里还有一个按钮** | §3.5：只有 Alt + 点 | Alt 不容易被发现，也不方便触控板用户；按钮同时说明了快捷键 |
| 6 | 吸管吸到以后，悬停同类时**预览粘贴效果** | 没写 | 和选择器的「悬停 = 预览」一致 |
| 7 | 点方案卡 = **先选中**，再点「套用」才写入 | §3.4 一致（「然后点『套用』按钮才写入」） | 一致；另外补了影响数、0 项时禁用、toast 的条件变化 |
| 8 | 装修用量**不进合计** | §3.6「不计价」 | 一致；明确合计芯片和底部合计不变 |
| 9 | 吊柜碰到窗时**那一段不装**，并且提示原因 | §8：「只提了方向」 | 给出一条可预期的规则；提示让用户知道为什么少了一段 |
