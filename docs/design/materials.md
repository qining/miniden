## 0. 怎么读

### 0.1 三条约定（沿用 facelift §0.1）

1. **id 和处理器尽量不动**。S25 的影子控件（`#rmFloor` `#rmWall` `#rmAngle` `#lvFloor` `#dKind` `#dWood` `#wWinFrame` `#wWinFrost` `#wWinCurtain` / `#wWinCurtainSel` 等）继续留在 DOM 里当**状态源和处理器入口**；新视图（材质行、选择器、小图示）只做两件事：赋值 / 派发 `change` / `click()`，以及读取值来显示选中态。
2. **新字段全部可选**。不设新字段的旧文档、内置户型，2D 和 3D 必须和现在一模一样（§8 的约束）。所以每个新选项列表的**第一项都是「缺省」**，它的外观等于现在写死的样子（§7.4 列出了这些值）。
3. **`#calib` 不受影响**：新的 2D 元素（墙面色带、洁具新图例、选中墙面的描边）全部走 `!CALIB` 分支，并且只在「装修」分区里画（§5.5、§11）。

## 1. 设计原则

1. **对象优先**：先选中一个东西（2D 里点、左栏点房间、检视面板里点「这个房间的墙」），检视面板只列它的几行。检视面板**不再整片铺色块**（解决 research §3.1-a/b/c）。
2. **选项多少决定控件**（本规格的核心规则）：

   | 选项数 | 控件 | 例子 |
   |---|---|---|
   | 2–4 个，文字短 | 分段控件 `.seg.sm` | 铺法、方向、墙砖高度、宽度档、落地 / 悬挂、玻璃 |
   | 2–8 个，形状不同 | **小图示单选** `.icons`（图示 + 两到四个字） | 洗手台形式、马桶、淋浴、浴缸、门板、窗格、帘型、柜门板 |
   | ≤ 8 个，颜色 / 材质 | **一排色块** `.swRow`，直接放在检视面板里 | 门颜色（7 + 自定义）、窗框 5、台面（缺省 + 6）、百叶颜色 3 |
   | > 8 个 | **材质行** `.mrow` → 左栏**选择器** | 地面 45、墙面（42 色 + 24 墙纸）、墙砖 8 + 无、柜色、窗帘颜色 16 / 42 |

3. **「是什么」放在选择器里，「怎么铺」放在检视面板里**：材质本身（哪种木地板、哪种砖）在选择器里挑；铺法、方向、墙砖高度这些是「这一次怎么用」，跟着材质行放在检视面板里，关掉选择器以后还看得见、改得了（§13 分歧 3）。
4. **悬停 = 预览，点击 = 确定，Esc = 撤回**：在选择器里悬停时，2D 和 3D 都立刻换上，移开就恢复；点一下才写进文档（一步撤销）。
5. **2D 只做提示**：墙面色带和房间行里的三个小色块告诉你「这里设过什么」，不去模拟图案（research §0-5）。

## 2. 材质行（检视面板）

### 2.1 材质行的结构 `.mrow`

```
┌──────────────────────────────────────────────┐
│ ┌────┐ 地面                      [单独设置] ▸ │  ← 行名（11px 灰）· 状态芯片 · ▸
│ │缩略│ 白色哑光砖                              │  ← 名字（13px，一行，超长省略号）
│ └────┘ 60 × 60 · 直缝                          │  ← 规格（11px 灰）
└──────────────────────────────────────────────┘
  高 46，内边距 6 / 8，缩略图 36 × 36，整行都可点（<button>）
```

| 状态 | 外观 |
|---|---|
| 常态 | `--panel2` 底，1px `--line` 边 |
| 悬停 | 边变成 `--muted` |
| **打开中**（选择器正在改它） | `--sel-bg` 底 + `--accent-line` 边 + 左侧 3px 琥珀内阴影；▸ 换成 ◂ |
| 预览中 | 名字后面加「（预览中）」，缩略图换成预览的材质 |
| 「无」 | 缩略图是灰色斜纹（`.mt.none`），名字写「无」 |

状态芯片 `.st`（只在需要分清「继承」还是「自己设的」时出现）：

| 芯片 | 含义 | 样式 |
|---|---|---|
| 跟全屋 | 房间没单独设地面 | 灰边 |
| 这个房间 / 单独设置 | 房间单独设了地面；墙面单独设置 | `--accent-line` 边 + 琥珀字（`.st.own`） |
| 跟房间 | 单面墙沿用房间的设置 | 灰边 |
| 整个房间 | 房间级的墙砖 / 墙面 | 琥珀 |

点一行 = 在左栏打开选择器，选择器的目标就是这一行（§3）。选择器开着时再点另一行 = 直接换目标，不关闭。

### 3.4 交互

| 动作 | 结果 |
|---|---|
| 点材质行 | 打开选择器，目标 = 这一行；材质行变成「打开中」 |
| 鼠标进入一格，停 **120ms** | **预览**：这个对象在 2D 和 3D 里临时换上（不写文档、不进撤销、不保存）；这一格加蓝色预览环（`--preview-line`）；`#mpReadout` 显示名字 + 规格 +「预览中」；材质行显示「（预览中）」 |
| 在格子之间移动 | 直接换预览，不先恢复（避免闪） |
| 鼠标离开网格区 **80ms** 以后 | 恢复到当前值 |
| 键盘：方向键在网格里移动焦点 | 焦点 = 预览（和悬停一样） |
| **点一格 / 回车** | **确定**：写进文档，一步撤销，存档；这一格变成 ✓；**选择器不关**，可以接着比较（读数标签从「预览中」变成「已用上」，1.2s 后消失） |

| 选择器开着时，在画布上点别的对象 | 新对象有同一个槽位（比如另一个房间的地面）→ 换目标，选择器不关；没有 → 关闭 |

| ⌘Z | 照常撤销；选择器的 ✓ 跟着刷新 |

### 3.5 搜索、色调、最近用过、这套房子已用、密度

- **搜索** `#mpSearch`：输入时自动切到「全部」页签，按名字、规格、分类、色系和同义词匹配，不区分全角半角。同义词：
  - 「白」→ 所有名字里带白的，以及白色系；「灰」「木」「橡」「砖」同理
  - 「大理石」→ 石材类；「60」→ 60×60、60×120；「地铁」→ 地铁砖；「人字」→ 人字拼、人字纹
  - 搜不到：「没找到“{词}”。试试颜色（白、灰）或规格（60×60）。」
- **色调** `#mpTone`：
  - 浅 / 中 / 深按 CIELAB 明度 L\* 分：浅 ≥ 75，中 45–75，深 < 45。
  - 暖 / 冷按色相分：彩度 C\* > 6 时，色相 0–90° 或 300–360° 算暖，90–300° 算冷；C\* ≤ 6 的中性色两边都不算。
  - 同一组里多选是「或」，两组之间是「且」。材质按代表色（`tint`）算。
  - 筛选有值时，页签上的数字跟着变。
- **最近用过**：按槽位类型分四类记录（地面 / 墙面 / 墙砖 / 颜色——门、柜体、布料共用「颜色」这一类），每类最多 8 个，最新的在左；自定义颜色也进来。存 `localStorage` 键 `md_matRecent_v1`。没有记录时这一行不显示。
- **这套房子已用**：统计当前户型（所有楼层）里这一类用到的材质，按次数降序，最多 8 个，右上角 `×N`。不跟方案走（装修外观本来就不跟方案走）。
- 两排小方块的行为和网格格子一样（悬停预览、点击确定）。
- **密度** `#mpDensity`：▦ 大图（3 列，图 4:3 + 名字 + 规格）/ ▪▪ 小图（5 列，方图，名字只在读数里）。按槽位类型记住，键 `md_matDensity_v1`。色板槽的「小图」就是色板矩阵（§4.1），「大图」是 3 列带色名。

## 5. 墙面

### 5.1 两层：整个房间 + 单面墙覆盖

| 层 | 数据（建议，工程定） | 界面 |
|---|---|---|
| 整个房间 | `room.wallColor`（现有）· **新** `room.wallMat?`（墙纸）· **新** `room.tile?`（墙砖 + 高度 + 铺法） | 房间检视的「墙面」「墙砖」两行 |
| 单面墙 | **新** `room.faces?[]`：按「房间 + 这条墙线」存（端点 + 法线，共线判定；research §3.2，开窗把墙拆成三段时覆盖不丢） | 单面墙检视 |

- 墙面槽的取值是**涂料或墙纸二选一**；墙砖是叠在上面的一层（从地面铺到「高度」为止），砖以上露出墙面。
- 单面墙的「墙面」「墙砖」各自独立地「跟房间」或「单独设置」。
- 清除单独设置 = 两项都回到跟房间（`#faceClear`）；单项清除 = 在选择器里点第一格「跟房间」。

### 5.2 怎么选中一面墙

- 装修的「选择」工具（`data-t="deco"`），点击时的判定顺序：
  1. 门、窗、洁具、台面（和现在一样）
  2. **墙面**：点在某个房间里，并且离这个房间的某面墙的内皮 ≤ **max(30 cm, 10 屏幕像素)** → 选中这面墙的房间一侧
  3. 房间（和现在一样）
- **悬停预高亮**：鼠标进入墙面判定区，这面墙的房间一侧就出现 2px 琥珀虚线框（色带外框），光标变成指针；提示行写「点一下 = 只改这面墙（上墙 · 366 cm）」。
- **命名**：按平面图方位写「上墙 / 右墙 / 下墙 / 左墙」（平面图不一定上北下南，所以不用东南西北）。斜墙按法线方向归到最近的那一侧；同一侧有几段时，从左到右或从上到下编号：「上墙 1」「上墙 2」。后面都跟长度：「上墙 · 366 cm」。
- **3D 里**（3D 点选是 S27 的事）：通过房间检视里的「这个房间的墙 ▸」列表来选，每行可点。
- 选中墙面时，2D 里这面墙的色带外框是 2px 实线琥珀；如果选择器正在预览，换成蓝色（`--preview-line`），旁边写「预览：墨绿」（原型 `#wall`）。
- 选中墙面后按 Esc → 回到选中这个房间（一层一层退：墙面 → 房间 → 全不选），和 S25 的 Esc 规则一致。

### 5.3 「应用到…」（`#mpScope`）

| 从哪打开 | 显示 | 缺省 |
|---|---|---|
| 单面墙的「墙面」/「墙砖」 | [这面墙 \| 整个房间] | 这面墙 |
| 房间的「墙面」/「墙砖」 | [这面墙（禁用）\| 整个房间]，后面灰字「先在平面图上点一面墙才能只改那面」 | 整个房间 |
| 其他槽位 | 不显示 | — |

- 在单面墙上切到「整个房间」= 选择器的目标换成房间。这时点一格，会写进房间的设置，**并且清掉这面墙的单独设置**；否则用户会看到「我点了，选中的这面墙却没变」。其他墙的单独设置不动，读数里说一句「另有 N 面墙单独设置，不受影响」。
- 切回「这面墙」= 目标换回这面墙。

## 8. 缩略图（程序化生成，不用外部图片）

### 8.1 画法

- 每一类材质只有**一个画法函数** `drawMat(ctx, mat, pxPerCm)`。3D 贴图（≤ 512px）和缩略图都调用它，只是传入的比例不同，所以两边看起来一样。原型里的 `thumb()` 就是这个思路的演示（木板错缝、人字、方砖、地铁砖、六角、棋盘、大理石纹、水磨石、洞石、花砖、噪声、8 种墙纸、木纹、不锈钢）。
- **统一真实比例**：地面、墙砖、墙纸的缩略图都代表 **120 × 90 cm** 的一块，所以宽板和窄板、7.5 × 15 和 10 × 20 放在一起比，大小是对的。台面代表 60 × 45 cm，木纹色块代表 40 × 40 cm。
- 随机数按材质 id 固定种子，同一个材质每次画出来都一样（黄金截图才稳定）。
- 纯色（色板、门色、柜色、布料）**不用 canvas**，直接用 CSS 背景色。

### 8.2 尺寸

| 用在哪 | 显示（CSS px） | 画布（2 倍屏） |
|---|---|---|
| 选择器 · 大图 | 89–101 宽 × 4:3 | 192 × 144 |
| 选择器 · 小图 | 51–58 方 | 用 192 × 144 那张，中心裁成方的（不另画） |
| 墙纸行 | 89–101 宽 × 2:1 | 192 × 96 |
| 最近用过 / 已用 | 36 × 36 | 72 × 72（从 192 × 144 裁） |
| 材质行 | 36 × 36 | 同上 |
| 房间行三个小色块 | 14 × 14 | 28 × 28 |
| 台面一排 | 30–34 方 | 68 × 68 |
| 门 / 柜的木色格 | 24 方 | 48 × 48 |

### 8.3 生成与缓存

- **懒生成**：选择器打开时，只画进入可视区的格子（`IntersectionObserver`）；每帧最多 4 张，用 `requestAnimationFrame` 分批，没画好的格子先用材质的 `tint` 纯色占位。
- **缓存**：`Map`，键是 `${id}@${w}x${h}`，值是 JPEG dataURL（质量 0.85，每张约 5–8 KB）。45 种地面 + 8 种墙砖 + 24 种墙纸 + 7 种台面 ≈ 84 张 × 约 7 KB ≈ 0.6 MB，切换户型也不清。
- **小图示**（洁具形式、门板、窗格、帘型、柜门）：内联 SVG（`viewBox="0 0 30 30"`，`stroke-width:1.4`，`fill:none`），选中时描边变成 `--accent`。洁具的那几种和 2D 图例共用一组路径定义（2D 按真实尺寸缩放，图示归一化）。

## 13. 与 research/15 的分歧（以及理由）

| # | 本规格的做法 | research 的说法 | 理由 |
|---|---|---|---|
| 1 | 选择器**沿用左栏当前宽度**（1280 = 307，1440 = 346），不改成固定 340 | §3.2「宽约 340px」 | 临时加宽会让画布变窄、平面图重新取景，**悬停预览的位置会跳**，正好破坏这个功能最核心的体验；307 宽也能放 3 列（每格 89px，原型实测）|
| 2 | **≤ 8 个选项直接放在检视面板里**（门色 8、门板 5、窗格 4、帘型 8、台面 7、洁具形式），不全走「材质行 → 选择器」 | §3.2：检视只列材质行，点了开选择器 | 少的选项开一个选择器反而多一步；一排 8 格加一行字，比一个材质行（46px）也高不了多少。多于 8 个的（地面、墙面、墙砖、柜色、布料）才走选择器 |
| 3 | 铺法、方向、墙砖高度放在**检视面板的子行**里，不放在选择器里 | §3.2 的线框没写；§3.3 的路径「选砖 → 高度选半高」暗示在同一处 | 这些是「这一次怎么用」，不是材质本身；关掉选择器以后还得看得见、改得了。新设墙砖时按房间类型给高度缺省值（卫生间 = 淋浴区、厨房 = 防溅区），所以 research 说的「5 下」不变 |
| 4 | 点一格 = 确定，但**选择器不关**；另加「↺ 还原」 | §3.2「点 = 确定，Esc = 撤回预览，回到上一层」 | 不关是为了能接着比较（悬停预览一移开就恢复，要比两种就得点下去看）；「还原」给「试了几种都不满意」一个一步回去的出口 |
| 5 | 在单面墙上选「整个房间」并点一格，会**同时清掉这面墙的单独设置** | 没写 | 否则用户选中这面墙、改了「整个房间」，眼前这面墙却不变，像是没生效 |
| 6 | 2D 色带**只画设过的墙**；没设过的白墙不画 | §3.2「每面墙的房间一侧画一条色带」 | 缺省全是白墙，全画会让平面图多出一圈白边，信息量为零 |
| 7 | 墙的命名用**上 / 右 / 下 / 左**（平面图方位） | 线框里写「床头墙」 | 平面图不一定上北下南；「床头墙」需要猜家具的用途，不可靠。自定义墙名是 P2 |
| 8 | 房间的窗帘颜色是**「窗帘」行里的一个色块**，不单独占一行材质行 | §3.2 线框是「窗帘 不挂（2 扇）▸」一整行 | 省 46px，保证选中房间时检视面板在 1440 下不用滚 |
| 9 | 「地板」全面改叫**「地面」** | research 混用 | 选项里有瓷砖、地毯、水泥；会改到 S25 的几条文案断言，在实现包里一起改写 |
| 10 | 白色系按明度重排（纯白 > 冷白 > 奶白 > 暖白 > 象牙白） | §2.1 的顺序 | 每行「从浅到深」要说到做到；色值和名字都没变 |
| 11 | 门颜色 8 格里「白」= 现在的门白、「胡桃」= 现在的深木色 | §2.5 只列了颜色名 | 保证旧文档和内置户型外观不变（§8 的约束）；需要工程核对 `matDoorW` / `matDoorWood` 的实际值 |
| 12 | 台面 / 橱柜的选项列表前面都加了「缺省」（现在写死的深咖柜、浅灰台面） | §2.10 列表里没有它们 | 同上：不设新字段时必须和现在一样，而它们不在 research 的列表里 |
| 13 | 旧的台柜 / 洗手盆这一轮**不给「转换成洗手台」按钮** | §2.7「旧的照常读出来、照常显示」 | 一致；只是明确不做转换（两件合成一件涉及位置和撤销，留给以后） |

没有采纳、和 §8 保持一致的：3D 点选、整屋配色、护墙板、踢脚线、天花颜色、五金色、填缝颜色、用量估算（都是 S27 候选）。
